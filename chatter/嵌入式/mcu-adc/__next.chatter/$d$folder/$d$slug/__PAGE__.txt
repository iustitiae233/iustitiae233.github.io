10:T1b6a,<h2>引言</h2>
<p>现实世界是模拟的——温度、湿度、压力、光线、声音，都是连续变化的物理量。而单片机只认识 0 和 1。ADC（模数转换器）就是连接这两个世界的桥梁。</p>
<h2>一、ADC 基本概念</h2>
<p>ADC（Analog to Digital Converter）将连续的模拟信号转换为离散的数字信号。转换过程包含四个核心步骤：</p>
<p>步骤说明**采样（Sampling）<strong>以固定时间间隔获取模拟信号的瞬时值</strong>保持（Hold）<strong>用电容保持采样值，防止转换期间信号变化</strong>量化（Quantization）<strong>将连续的模拟值划分为离散的数字级别</strong>编码（Encoding）**将量化结果以二进制形式输出</p>
<h2>二、核心参数详解</h2>
<h3>1. 分辨率（Resolution）</h3>
<ul>
<li>STM32 F1/F4 系列：典型 <strong>12 位</strong>分辨率，输出范围 0 ~ 4095（2¹² - 1）</li>
<li>STM32 H7 系列：最高 <strong>16 位</strong>分辨率，过采样可达 26 位</li>
</ul>
<p><strong>LSB（最低有效位）计算公式：</strong></p>
<pre><code class="hljs language-cpp">LSB = Vref+ / <span class="hljs-number">2</span>^分辨率位数
</code></pre>
<p>以 12 位分辨率、参考电压 3.3V 为例：</p>
<pre><code class="hljs language-cpp">LSB = <span class="hljs-number">3.3</span>V / <span class="hljs-number">4096</span> ≈ <span class="hljs-number">0.806</span>mV
实际电压 = ADC转换值 × (<span class="hljs-number">3.3</span> / <span class="hljs-number">4096</span>)
</code></pre>
<h3>2. 采样率（Sampling Rate）</h3>
<p>关键参数F1 系列典型值说明ADC 时钟最高14 MHz超过会降低精度常用分频配置PCLK2 的 8 分频 = 9 MHzADCCLK 必须 ≤ 14MHz最短采样周期1.5 个 ADCCLK 周期可编程范围：1.5 ~ 239.5 周期</p>
<p><strong>总转换时间公式：</strong></p>
<pre><code class="hljs language-cpp">Tconv = 采样时间 + <span class="hljs-number">12.5</span> 个周期（逐次逼近固定时间）
</code></pre>
<blockquote>
<p>最快转换时间（F1）：Tconv = (1.5 + 12.5) × (1/12MHz) ≈ <strong>1.17 μs</strong></p>
</blockquote>
<h3>3. ADC 类型</h3>
<p>STM32 采用<strong>逐次逼近型（SAR）ADC</strong>，在精度和速度之间取得良好平衡。</p>
<h2>三、工作模式</h2>
<h3>转换模式</h3>
<p>模式说明<strong>单次转换</strong>触发一次，执行一次转换后停止<strong>连续转换</strong>一次触发后，不断循环转换<strong>扫描模式</strong>按预设顺序轮流采集多个通道<strong>间断模式</strong>分组间断地进行多通道转换</p>
<h3>通道组</h3>
<p>通道组通道数特点**规则通道组（Regular）<strong>最多 16 路正常运行，结果存于单个数据寄存器</strong>注入通道组（Injected）**最多 4 路类似中断，可打断规则通道转换</p>
<h3>触发方式</h3>
<ul>
<li><strong>软件触发</strong>：代码直接启动转换</li>
<li><strong>外部事件触发</strong>：定时器、EXTI 外部中断等</li>
</ul>

<h2>五、DMA 模式 —— 多通道/高速采集</h2>
<p>对于多通道或高速持续采集，推荐使用 <strong>DMA 循环传输模式</strong>，由 DMA 自动将 ADC 数据搬移到内存数组，无需 CPU 频繁干预：</p>
<pre><code class="hljs language-cpp"><span class="hljs-comment">// DMA 关键配置</span>
DMA_InitStructure.DMA_Mode = DMA_Mode_Circular;              <span class="hljs-comment">// 循环模式</span>
DMA_InitStructure.DMA_PeripheralBaseAddr = ADC1_DR_Address;  <span class="hljs-comment">// ADC数据寄存器</span>
DMA_InitStructure.DMA_MemoryBaseAddr = (<span class="hljs-type">uint32_t</span>)&#x26;adc_buffer; <span class="hljs-comment">// 内存数组</span>
DMA_InitStructure.DMA_BufferSize = 通道数量;
</code></pre>
<p>这样 ADC 持续采集，DMA 自动搬运，CPU 只需在需要时读取 <code>adc_buffer</code> 即可。</p>
<h2>六、常见问题与注意事项</h2>
<p>问题原因解决方案<strong>外部阻抗过大导致误差</strong>分压电阻过大（MΩ 级），与内部 50kΩ 阻抗分压使用 ≤10kΩ 分压电阻，或加运放做阻抗变换<strong>多通道串扰</strong>采样电容在通道切换时残留电荷增大通道间采样延时<strong>引脚浮空</strong>外部无输入时引脚悬空加下拉电阻<strong>扫描模式数据覆盖</strong>规则组只有一个数据寄存器及时读取或使用 DMA<strong>ADC 时钟超频</strong>ADC 时钟 >14MHz正确配置分频因子</p>

<h2>总结</h2>
