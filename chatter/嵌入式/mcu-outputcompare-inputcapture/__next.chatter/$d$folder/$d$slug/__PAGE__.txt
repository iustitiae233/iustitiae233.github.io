10:T1c87,<h2>引言</h2>
<p>如果说定时器的基本定时功能是它的"心跳"，那么输出比较和输入捕获就是它的"双手"——一手创造信号，一手测量信号。理解这两个功能，是掌握 PWM、频率计、超声波测距等应用的前提。</p>
<h2>一、核心概念：CNT 与 CCR</h2>
<p>理解输出比较和输入捕获，关键在于两个寄存器的关系：</p>
<p>寄存器含义在 IC 中在 OC 中<strong>CNT</strong>计数器时间标尺时间标尺<strong>CCR</strong>捕获/比较寄存器<strong>保存</strong> CNT 的快照值<strong>与</strong> CNT 比较，匹配时触发动作</p>
<blockquote>
<p>💡 <strong>一句话理解：</strong></p>
<ul>
<li><strong>输入捕获（IC）</strong>：外部信号边沿到来时，<strong>把 CNT 的当前值"拍照"存入 CCR</strong></li>
<li><strong>输出比较（OC）</strong>：CNT 数到与 CCR 相等时，<strong>触发硬件动作</strong></li>
</ul>
</blockquote>
<h2>二、输入捕获（Input Capture）</h2>
<h3>2.1 工作原理</h3>
<pre><code class="hljs language-cpp">                    ┌─────── 捕获上升沿 ───────┐
                    │                          │
     外部信号:  ────┘                          └───────
                    │                          │
     CNT值:    ... <span class="hljs-number">100</span> ... <span class="hljs-number">200</span> ... <span class="hljs-number">300</span> ... <span class="hljs-number">400</span> ... <span class="hljs-number">500</span> ...
                    ↑                          ↑
                  CCR=<span class="hljs-number">100</span>                    CCR=<span class="hljs-number">500</span>

     脉冲宽度 = <span class="hljs-number">500</span> - <span class="hljs-number">100</span> = <span class="hljs-number">400</span> 个计数周期
</code></pre>
<p><strong>工作流程：</strong></p>
<ol>
<li>配置通道为输入捕获模式，选择触发边沿（上升沿 / 下降沿 / 双边沿）</li>
<li>当指定边沿到来时，硬件自动将当前 <strong>CNT 的值复制到 CCR</strong> 中</li>
<li>连续捕获两次，<strong>两次 CCR 的差值</strong>就是两个边沿之间的时间</li>
<li>配合计数频率换算出实际时间：<code>时间 = 差值 × 计数周期</code></li>
</ol>
<h3>2.2 测量频率</h3>
<p>频率测量常用<strong>两次上升沿捕获法</strong>：</p>
<pre><code class="hljs language-cpp">f_signal = f_cnt / (CCR2 - CCR1)
</code></pre>
<p>其中 <code>f_cnt</code> 是 CNT 的计数频率 = <code>TIM_CLK / (PSC + 1)</code></p>
<h3>2.3 典型应用</h3>
<p>应用说明频率计测量外部信号的频率占空比测量同时测量 PWM 信号的高电平与周期红外遥控解码测量编码脉冲的宽度超声波测距测量 Echo 引脚高电平持续时间编码器测速通过捕获正交编码器脉冲测量转速</p>
<h3>2.4 HAL 配置示例</h3>
<pre><code class="hljs language-cpp">TIM_IC_InitTypeDef sConfigIC = {<span class="hljs-number">0</span>};

sConfigIC.ICPolarity  = TIM_ICPOLARITY_RISING;   <span class="hljs-comment">// 上升沿捕获</span>
sConfigIC.ICSelection = TIM_ICSELECTION_DIRECTTI; <span class="hljs-comment">// 直接映射到 TIx</span>
sConfigIC.ICPrescaler = TIM_ICPSC_DIV1;           <span class="hljs-comment">// 不分频</span>
sConfigIC.ICFilter    = <span class="hljs-number">0x0</span>;                      <span class="hljs-comment">// 数字滤波</span>
<span class="hljs-built_in">HAL_TIM_IC_ConfigChannel</span>(&#x26;htim2, &#x26;sConfigIC, TIM_CHANNEL_1);

<span class="hljs-comment">// 启动输入捕获中断</span>
<span class="hljs-built_in">HAL_TIM_IC_Start_IT</span>(&#x26;htim2, TIM_CHANNEL_1);
</code></pre>
<h2>三、输出比较（Output Compare）</h2>
<h3>3.1 工作原理</h3>
<pre><code class="hljs language-cpp">CNT:  <span class="hljs-number">0</span> ──→ <span class="hljs-number">30</span> ──→ <span class="hljs-number">60</span> ──→ <span class="hljs-number">90</span> ──→ ARR ──→ <span class="hljs-number">0</span> ──→ ...
              ↑
           CNT == <span class="hljs-built_in">CCR</span> (假设CCR=<span class="hljs-number">30</span>)
              │
         ┌────┴────┐
         │ 触发动作 │ → 翻转/置高/置低/中断
         └─────────┘
</code></pre>
<p>当 CNT 的值等于 CCR 时，发生"比较匹配"事件，触发预先配置的动作。</p>
<h3>3.2 八种输出比较模式</h3>
<p>模式匹配时行为典型用途<strong>冻结 (Frozen)<strong>输出保持不变暂停 PWM 输出</strong>匹配时置有效电平</strong>输出置高单次脉冲<strong>匹配时置无效电平</strong>输出置低单次脉冲<strong>匹配时翻转 (Toggle)<strong>电平取反生成 50% 占空比方波</strong>强制无效电平</strong>强制输出低强制停机<strong>强制有效电平</strong>强制输出高强制输出<strong>PWM 模式 1</strong>CNT &#x3C; CCR 高, CNT ≥ CCR 低<strong>最常用的 PWM 输出PWM 模式 2</strong>CNT &#x3C; CCR 低, CNT ≥ CCR 高PWM 模式 1 的反相版本</p>
<h3>3.3 典型应用</h3>
<p>应用说明LED 调光改变 PWM 占空比控制亮度电机调速PWM 控制直流电机转速舵机控制用特定脉宽控制角度生成参考方波Toggle 模式生成 50% 占空比方波外设同步信号匹配时触发 ADC 采样 / DMA 传输</p>
<h2>四、输入捕获 vs 输出比较 —— 对比总结</h2>
<p>维度输入捕获 (IC)输出比较 (OC)<strong>数据流向</strong>外部 → MCU（<strong>测量</strong>外部信号）MCU → 外部（<strong>产生</strong>信号）<strong>CNT 与 CCR 的关系</strong>边沿到来时，CNT → CCRCNT == CCR 时触发动作<strong>引脚方向</strong>输入输出（复用推挽）<strong>核心用途</strong>测频率、周期、脉宽、占空比输出 PWM、方波、脉冲<strong>中断事件</strong>捕获中断比较匹配中断<strong>共用资源</strong>同一通道同一时刻只能配置为 IC 或 OC</p>
<h2>五、常见问题与排查</h2>
<h3>CNT 溢出处理（输入捕获）</h3>
<p>当被测信号周期很长时，CNT 会在两次捕获之间溢出。必须统计溢出次数：</p>
<pre><code class="hljs language-cpp">实际时间 = 溢出次数 × (ARR + <span class="hljs-number">1</span>) + 最后一次 CCR 值
</code></pre>
<p>需要在更新中断中累加溢出计数。</p>
<h3>PWM 输出无波形？</h3>
<p>常见原因排查：</p>
<ol>
<li><strong>GPIO 未配置为复用推挽输出</strong></li>
<li><strong>未调用</strong> <code>HAL_TIM_PWM_Start()</code> 启动输出</li>
<li><strong>高级定时器（TIM1/TIM8）未使能主输出</strong>：需设置 MOE 位</li>
<li><strong>时钟未使能</strong></li>
</ol>
<h2>总结</h2>
<p>输出比较和输入捕获是定时器最强大的两个功能。一个向外创造，一个向内感知。理解了 CNT 与 CCR 之间"比较"与"捕获"的两种关系，你就掌握了定时器 80% 的应用场景。</p>
