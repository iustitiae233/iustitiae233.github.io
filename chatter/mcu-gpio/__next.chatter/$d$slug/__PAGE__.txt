e:T1872,<h2>引言</h2>
<p>GPIO（General Purpose Input/Output，通用输入输出）是单片机最基础也最常用的外设。无论是点亮一颗LED、读取一个按键，还是驱动复杂的通信总线，都离不开对GPIO的理解。</p>
<blockquote>
<p>如果说单片机是一个微型计算机，那么GPIO就是它与物理世界对话的窗口。</p>
</blockquote>
<h2>一、GPIO 内部结构</h2>
<p>STM32 的每个 I/O 引脚内部包含以下关键电路：</p>
<p>结构功能<strong>保护二极管</strong>防止引脚电压高于 VDD 或低于 VSS，保护芯片<strong>上拉/下拉电阻</strong>内部弱电阻（约 30~50kΩ），可通过寄存器配置<strong>施密特触发器</strong>将模拟信号整形成数字 0/1，输入模式下开启<strong>P-MOS + N-MOS 管</strong>实现推挽输出和开漏输出的核心驱动电路**输入数据寄存器 (IDR)<strong>每个 AHB 时钟周期采样一次引脚电平</strong>输出数据寄存器 (ODR)<strong>控制输出电平状态</strong>位设置/清除寄存器 (BSRR)**原子操作 ODR 的各个位，不会被中断打断</p>
<h2>二、8 种 GPIO 工作模式</h2>
<h3>📥 4 种输入模式</h3>
<ol>
<li>浮空输入（Input Floating）</li>
</ol>
<ul>
<li>上拉和下拉电阻<strong>均断开</strong></li>
<li>引脚悬空时电平不确定，易受外部噪声干扰</li>
<li><strong>典型应用</strong>：I2C、USART 的 RX 端、ADC 输入</li>
</ul>
<ol start="2">
<li>上拉输入（Input Pull-Up）</li>
</ol>
<ul>
<li>内部<strong>上拉电阻接通</strong>到 VDD</li>
<li>引脚悬空时保持<strong>高电平</strong></li>
<li><strong>典型应用</strong>：按键检测（按键接地，平时高电平，按下低电平）</li>
</ul>
<ol start="3">
<li>下拉输入（Input Pull-Down）</li>
</ol>
<ul>
<li>内部<strong>下拉电阻接通</strong>到 VSS</li>
<li>引脚悬空时保持<strong>低电平</strong></li>
<li><strong>典型应用</strong>：按键检测（按键接 VDD，平时低电平，按下高电平）</li>
</ul>
<ol start="4">
<li>模拟输入（Analog）</li>
</ol>
<ul>
<li>上拉/下拉断开，施密特触发器关闭</li>
<li>电压信号直接传入 ADC 模块</li>
<li><strong>典型应用</strong>：ADC 电压采集、省电模式下的未用引脚</li>
</ul>
<h3>📤 4 种输出模式</h3>
<ol start="5">
<li>推挽输出（Push-Pull）</li>
</ol>
<ul>
<li><strong>P-MOS + N-MOS 双管工作</strong>：输出 1 时 P-MOS 导通，输出 0 时 N-MOS 导通</li>
<li>驱动能力强，上升沿速度快</li>
<li><strong>典型应用</strong>：LED 驱动、普通 GPIO 输出</li>
</ul>
<ol start="6">
<li>开漏输出（Open-Drain）</li>
</ol>
<ul>
<li><strong>只有 N-MOS 管工作</strong>：输出 0 强拉到地，输出 1 需外部上拉</li>
<li>具备<strong>线与</strong>功能，可实现电平转换</li>
<li><strong>典型应用</strong>：I2C 总线、电平不匹配场合</li>
</ul>
<ol start="7">
<li>复用推挽输出（AF Push-Pull）</li>
</ol>
<ul>
<li>与推挽输出相同，但信号源来自片上外设（SPI、USART、定时器）</li>
<li><strong>典型应用</strong>：USART TX、SPI MOSI/SCK</li>
</ul>
<ol start="8">
<li>复用开漏输出（AF Open-Drain）</li>
</ol>
<ul>
<li>与开漏输出相同，信号源来自片上外设</li>
<li><strong>典型应用</strong>：I2C SCL/SDA</li>
</ul>
<h2>三、推挽 vs 开漏 —— 核心对比</h2>
<p>特性推挽输出开漏输出驱动管P-MOS + N-MOS仅 N-MOS输出高电平<strong>强高电平</strong>（芯片内部驱动）<strong>需外部上拉电阻</strong>输出低电平强低电平强低电平电平转换不支持<strong>支持</strong>线与功能不支持（短路风险）<strong>支持</strong>典型应用LED、普通 IOI2C、电平匹配</p>
<h2>四、关键寄存器速查</h2>
<p>寄存器功能<strong>GPIOx_CRL/CRH</strong>配置引脚模式（每 4 位控制一个引脚）<strong>GPIOx_IDR</strong>读取引脚输入电平（只读）<strong>GPIOx_ODR</strong>设置/读取输出电平<strong>GPIOx_BSRR</strong>原子位操作（低 16 位置位，高 16 位清零）<strong>GPIOx_BRR</strong>位清零寄存器<strong>GPIOx_PUPDR</strong>配置上拉/下拉（F4/F7/H7 系列）<strong>GPIOx_OTYPER</strong>配置输出类型：0=推挽，1=开漏</p>
<h2>五、常用配置速查表</h2>
<p>应用场景推荐模式按键检测（接地）上拉输入按键检测（接 VDD）下拉输入LED 驱动推挽输出I2C 通信复用开漏输出 + 外部上拉USART TX复用推挽输出USART RX浮空输入ADC 采样模拟输入未用引脚模拟输入（省电 + 抗干扰）需要 5V 高电平输出开漏输出 + 外部 5V 上拉</p>
