e:T1f40,<h2>引言</h2>
<p>PWM（Pulse Width Modulation，脉冲宽度调制）是利用数字输出来模拟模拟电路控制的一种技术。它看似简单——只是控制高低电平的时间比例——但几乎是嵌入式系统中最常用的信号输出方式。从呼吸灯到电机调速，从舵机控制到音频合成，PWM 无处不在。</p>
<h2>一、PWM 基本概念</h2>
<h3>关键参数</h3>
<p>参数定义公式**周期（T）<strong>一个完整波形从开始到重复的时间T = 1/f</strong>频率（f）<strong>单位时间内完整周期的次数f = 1/T</strong>占空比（D）**高电平时间占整个周期的比例D = Ton / T × 100%<strong>分辨率</strong>占空比可调节的最小步距由 ARR 决定</p>
<blockquote>
<p>例：5V 系统，占空比 50% → 等效输出电压 ≈ 2.5V</p>
</blockquote>
<h2>二、STM32 PWM 生成原理</h2>
<p>STM32 通过<strong>定时器输出比较的 PWM 模式</strong>生成 PWM 信号。核心寄存器：</p>
<p>寄存器作用<strong>TIMx_PSC</strong>（预分频器）对时钟频率进行分频<strong>TIMx_ARR</strong>（自动重装载）决定 PWM 的<strong>周期/频率TIMx_CCRx</strong>（捕获/比较）决定 PWM 的<strong>占空比TIMx_CNT</strong>（计数器）当前计数值，不断与 CCRx 比较</p>
<h3>工作流程（向上计数、PWM 模式 1）</h3>
<pre><code class="hljs language-cpp">高电平
  ↑     ┌──────┐        ┌──────┐
  │     │      │        │      │
  │─────┘      └────────┘      └────→
  │  ← CCRx →←── (ARR-CCRx) ──→
  │  ←─────── 一个周期 (ARR<span class="hljs-number">+1</span>) ─────→
</code></pre>
<ol>
<li>计数器 CNT 从 0 向上累加</li>
<li><strong>CNT &#x3C; CCRx 时</strong> → 输出高电平</li>
<li><strong>CNT ≥ CCRx 时</strong> → 输出低电平</li>
<li><strong>CNT = ARR 时</strong> → CNT 清零，开始下一个周期</li>
</ol>
<h2>三、频率与占空比计算公式</h2>
<h3>PWM 频率</h3>
<pre><code class="hljs language-cpp">PWM频率 = 定时器时钟频率 / [(PSC + <span class="hljs-number">1</span>) × (ARR + <span class="hljs-number">1</span>)]
</code></pre>
<h3>占空比（PWM 模式 1）</h3>
<pre><code class="hljs language-cpp">占空比 = CCRx / (ARR + <span class="hljs-number">1</span>) × <span class="hljs-number">100</span>%
</code></pre>
<h3>配置示例</h3>
<blockquote>
<p><strong>目标</strong>：产生 1KHz、50% 占空比的 PWM<br>
<strong>时钟</strong>：72MHz<br>
• 设 PSC = 71 → 计数时钟 = 72MHz / 72 = 1MHz<br>
• 设 ARR = 999 → PWM频率 = 1MHz / 1000 = 1KHz<br>
• 设 CCRx = 500 → 占空比 = 500/1000 = 50%</p>
</blockquote>
<h2>四、频率与分辨率的权衡</h2>
<p>这是 PWM 配置中最需要理解的设计权衡：</p>
<p>取舍说明**频率 ↑**ARR ↓ → 分辨率 ↓**分辨率 ↑**ARR ↑ → 频率 ↓</p>
<blockquote>
<p><strong>示例</strong>：计数时钟 1MHz<br>
若要 100KHz PWM → ARR=9，分辨率仅 10 级<br>
若要 1KHz PWM → ARR=999，分辨率达 1000 级（0.1% 精度）</p>
</blockquote>
<h2>五、PWM 模式选择</h2>
<p>模式行为适用场景<strong>PWM Mode 1</strong>CNT &#x3C; CCR → 高电平通用场合<strong>PWM Mode 2</strong>CNT ≥ CCR → 高电平需要反相波形时</p>
<p>极性设置（<code>TIM_OCPolarity_High</code> / <code>TIM_OCPolarity_Low</code>）可进一步反转输出电平。</p>
<h2>六、HAL 库配置与代码</h2>
<h3>① CubeMX 配置</h3>
<ol>
<li>选择定时器（如 TIM3），Clock Source 设为 <code>Internal Clock</code></li>
<li>选择通道（如 Channel 1），设为 <code>PWM Generation CH1</code></li>
<li>设置参数：Prescaler、Counter Period（ARR）、Pulse（初始 CCRx）</li>
</ol>
<h3>② 呼吸灯示例</h3>
<pre><code class="hljs language-cpp"><span class="hljs-comment">// 启动 PWM 输出</span>
<span class="hljs-built_in">HAL_TIM_PWM_Start</span>(&#x26;htim3, TIM_CHANNEL_1);

<span class="hljs-comment">// 动态修改占空比实现呼吸灯</span>
<span class="hljs-keyword">while</span> (<span class="hljs-number">1</span>) {
    <span class="hljs-keyword">for</span> (<span class="hljs-type">uint16_t</span> i = <span class="hljs-number">0</span>; i &#x3C; <span class="hljs-number">1000</span>; i += <span class="hljs-number">10</span>) {
        __HAL_TIM_SET_COMPARE(&#x26;htim3, TIM_CHANNEL_1, i);
        <span class="hljs-built_in">HAL_Delay</span>(<span class="hljs-number">20</span>);
    }
    <span class="hljs-keyword">for</span> (<span class="hljs-type">uint16_t</span> i = <span class="hljs-number">1000</span>; i > <span class="hljs-number">0</span>; i -= <span class="hljs-number">10</span>) {
        __HAL_TIM_SET_COMPARE(&#x26;htim3, TIM_CHANNEL_1, i);
        <span class="hljs-built_in">HAL_Delay</span>(<span class="hljs-number">20</span>);
    }
}
</code></pre>
<h3>③ 常用 API</h3>
<p>函数/宏功能<code>HAL_TIM_PWM_Start()</code>启动 PWM 输出<code>HAL_TIM_PWM_Stop()</code>停止 PWM 输出<code>__HAL_TIM_SET_COMPARE()</code>动态修改占空比<code>__HAL_TIM_GET_AUTORELOAD()</code>获取 ARR 值</p>
<h2>七、典型应用</h2>
<p>应用PWM 频率占空比范围说明<strong>LED 呼吸灯</strong>1-2KHz0-100%频率高于人眼闪烁感知<strong>舵机 SG90</strong>50Hz（20ms周期）2.5%-12.5%0.5ms=0°，2.5ms=180°<strong>直流电机调速</strong>16-20KHz0-100%避开人耳听觉范围<strong>无源蜂鸣器</strong>1-4KHz50%输出音频频率</p>
<h2>八、舵机控制详解</h2>
<p>舵机是 PWM 最经典的应用之一。以 SG90 为例：</p>
<pre><code class="hljs language-cpp">周期 = <span class="hljs-number">20</span>ms（<span class="hljs-number">50</span>Hz）

高电平持续 <span class="hljs-number">0.5</span>ms  →  舵机角度 <span class="hljs-number">0</span>°
高电平持续 <span class="hljs-number">1.0</span>ms  →  舵机角度 <span class="hljs-number">45</span>°
高电平持续 <span class="hljs-number">1.5</span>ms  →  舵机角度 <span class="hljs-number">90</span>°
高电平持续 <span class="hljs-number">2.0</span>ms  →  舵机角度 <span class="hljs-number">135</span>°
高电平持续 <span class="hljs-number">2.5</span>ms  →  舵机角度 <span class="hljs-number">180</span>°
</code></pre>
<p><strong>50Hz PWM 配置（72MHz 时钟）：</strong></p>
<pre><code class="hljs language-cpp">PSC = <span class="hljs-number">144</span> - <span class="hljs-number">1</span> = <span class="hljs-number">143</span>        → CK_CNT = <span class="hljs-number">72</span>MHz / <span class="hljs-number">144</span> = <span class="hljs-number">500</span>KHz
ARR = <span class="hljs-number">10000</span> - <span class="hljs-number">1</span> = <span class="hljs-number">9999</span>     → PWM周期 = <span class="hljs-number">10000</span>/<span class="hljs-number">500</span>K = <span class="hljs-number">20</span>ms
CCR值范围 = <span class="hljs-number">250</span> ~ <span class="hljs-number">1250</span>     → <span class="hljs-number">0.5</span>ms ~ <span class="hljs-number">2.5</span>ms

<h2>九、常见问题排查</h2>
