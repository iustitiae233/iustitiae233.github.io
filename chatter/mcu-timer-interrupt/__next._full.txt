39:T1d6c,<h2>引言</h2>
<p>定时器和中断是嵌入式系统的"心跳"与"神经系统"。定时器让单片机感知时间的流逝，中断让单片机能够及时响应外部事件。两者结合，构成了实时嵌入式系统的核心基础。</p>
<h2>一、核心组件概览</h2>
<p>STM32 定时器中断系统由三个核心部件协同工作：</p>
<p>部件作用<strong>定时器 (TIM)<strong>产生定时中断请求</strong>NVIC (嵌套向量中断控制器)<strong>判断优先级并决定是否响应中断</strong>CPU</strong>暂停当前任务，跳转到中断服务函数执行</p>
<h2>二、定时器核心寄存器</h2>
<p>寄存器全称功能<strong>CNT</strong>计数器根据时钟信号递增/递减计数<strong>PSC</strong>预分频器对输入时钟分频，扩展定时范围<strong>ARR</strong>自动重装载寄存器设定计数上限，CNT 达到 ARR 时触发更新事件<strong>DIER</strong>中断使能寄存器控制是否允许定时器事件触发中断<strong>SR</strong>状态寄存器包含 UIF（更新中断标志）等标志位</p>
<h3>定时计算公式</h3>
<pre><code class="hljs language-cpp">实际计数频率 CK_CNT = TIMxCLK / (PSC + <span class="hljs-number">1</span>)
中断周期 = (ARR + <span class="hljs-number">1</span>) / CK_CNT
</code></pre>
<blockquote>
<p><strong>示例</strong>：APB1 时钟 72MHz，PSC=71，ARR=999<br>
→ CK_CNT = 72MHz / 72 = 1MHz<br>
→ 中断周期 = 1000 / 1MHz = <strong>1ms</strong></p>
</blockquote>
<h2>三、中断触发完整流程</h2>
<pre><code class="hljs language-cpp"><span class="hljs-number">1.</span> CNT 计数到达 ARR 值
       ↓
<span class="hljs-number">2.</span> 硬件自动置位 UIF（更新事件标志）
       ↓
<span class="hljs-number">3.</span> 若 UIE（更新中断使能位）已使能
       ↓
<span class="hljs-number">4.</span> 定时器向 NVIC 发送中断请求
       ↓
<span class="hljs-number">5.</span> NVIC 根据优先级判断是否响应
       ↓ (若响应)
<span class="hljs-number">6.</span> CPU 暂停当前任务，保存现场，跳转到中断服务函数
       ↓
<span class="hljs-number">7.</span> ISR 中执行业务代码
       ↓
<span class="hljs-number">8.</span> 【关键】手动清除 UIF 标志位
</code></pre>
<h2>四、NVIC 中断优先级详解</h2>
<h3>抢占优先级 vs 响应优先级</h3>
<p>优先级类型作用<strong>抢占优先级</strong>决定中断是否可嵌套。高抢占优先级可以打断低抢占优先级的中断**响应优先级（子优先级）**抢占优先级相同时，若多个中断同时到达，响应优先级高者先处理</p>
<h3>优先级分组（5 组，4 位分配）</h3>
<p>分组抢占优先级位数子优先级位数抢占级数子优先级级数NVIC_PriorityGroup_004016NVIC_PriorityGroup_11328NVIC_PriorityGroup_22244NVIC_PriorityGroup_33182NVIC_PriorityGroup_440160</p>
<blockquote>
<p>数值越小，优先级越高。推荐使用 <strong>Group 2</strong>（4 级抢占 + 4 级子优先级），在嵌套能力和响应顺序之间取得平衡。</p>
</blockquote>

<h2>六、注意事项</h2>
<p>注意事项说明<strong>必须手动清除中断标志</strong>不调用 <code>TIM_ClearITPendingBit()</code> 会导致反复进入中断，程序卡死<strong>中断函数名要正确</strong>必须与启动文件中定义的中断向量名称一致<strong>ISR 内代码尽量简短</strong>复杂逻辑应设置标志位，在主循环中处理<strong>初始化时清除标志位</strong>在 <code>TIM_ITConfig</code> 之前调用 <code>TIM_ClearFlag</code> 防止误触发<strong>确认时钟总线</strong>TIM1/TIM8 挂 APB2，TIM2~TIM7 挂 APB1</p>
<h2>七、STM32 定时器分类</h2>
<p>类型定时器功能<strong>高级控制定时器</strong>TIM1、TIM83 对 PWM 互补输出，常用于三相电机驱动<strong>通用定时器</strong>TIM2~TIM5定时、PWM 输出、输入捕获、编码器接口<strong>基本定时器</strong>TIM6、TIM7仅定时功能，无外部 IO</p>
