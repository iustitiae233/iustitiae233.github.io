f:T11a7b,<h2>一、电容是什么？</h2>
<p>电容的物理结构其实非常简单——<strong>两块导体板中间夹一层绝缘介质</strong>。就像两块大铁板面对面放着，中间隔一层空气或塑料薄膜，这就是一个电容。</p>
<p>电容的核心能力是<strong>储存电荷</strong>。当你给电容两端加上电压，正极板上会积累正电荷，负极板上会积累负电荷，中间隔着绝缘层，电荷跑不掉，于是电能就被"锁"在了电容里面。</p>
<blockquote>
<p>💡 <strong>通俗类比</strong>：电容就像一个<strong>弹性水袋</strong>——你把水压进去，它鼓起来存着；你把外面的压力撤掉，它就慢慢把水放出来。刚灌水时水袋是空的，对水流几乎没有阻力（相当于导线）；灌满了就对水流彻底堵死（相当于断路）。</p>
</blockquote>
<p>电容储电是一个<strong>物理过程</strong>，不是化学反应。所以电容充放电速度极快，寿命也比电池长得多，但能存的能量远远不如电池。</p>

<p>这是电容最根本、最重要的特性，源自电容的基本公式：</p>

<p>上电前，电容两端电压为 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>0</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">0\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">0</span><span class="mord text"><span class="mord">V</span></span></span></span></span>。上电瞬间：</p>
<ul>
<li>电源电压突然从 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>0</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">0\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">0</span><span class="mord text"><span class="mord">V</span></span></span></span></span> 跳到 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>5</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">5\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">5</span><span class="mord text"><span class="mord">V</span></span></span></span></span></li>
<li>但电容电压依然是 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>0</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">0\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">0</span><span class="mord text"><span class="mord">V</span></span></span></span></span>（不能突变！）</li>
<li>电容两端出现 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>5</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">5\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">5</span><span class="mord text"><span class="mord">V</span></span></span></span></span> 的电压差</li>
<li>此时电容表现得像<strong>短路/导线</strong>，电流猛冲进去给电容充电</li>
</ul>
<blockquote>
<p>这就是为什么电路板刚通电时会有瞬间大电流（<strong>浪涌电流</strong>），电路设计时必须考虑某个大电容上电时的冲击。</p>
</blockquote>
<p>随着充电进行，电容两端电压缓慢上升，电流逐渐减小。当电压充到接近电源电压时，电流趋于零，此时电容等效为<strong>断路</strong>。</p>
<p>这个"刚上电像导线，充满了像断路"的特性，就是所谓的<strong>隔直通交</strong>：</p>
<ul>
<li><strong>通交</strong>：交流信号（电压不断变化）时，电容反复充放电，总有电流流过——相当于导通</li>
<li><strong>隔直</strong>：直流稳定后，电容电压充到和电源一样，没有电压差就没有电流——相当于断开</li>
</ul>
<hr>

<h3>实际应用</h3>
<ul>
<li><strong>延时灯</strong>：用一个电容 + 电阻给三极管提供基极电压。关灯后，电容慢慢放电，灯不是立刻熄灭而是缓缓变暗。</li>
<li><strong>单片机复位电路</strong>：上电瞬间给 RESET 脚一个短暂的低电平脉冲（电容刚上电像导线，把 RESET 拉低），等电容充满后 RESET 变高电平，芯片开始正常工作。</li>
<li><strong>消抖电路</strong>：按键并联一个小电容，按键抖动产生的短暂毛刺被电容吸收掉，只有持续的高/低电平才能被识别。</li>
</ul>

<h2>四、电容稳压和滤波功能</h2>
<h3>稳压（旁路/去耦）</h3>
<p>这就是每块电路板电源引脚旁边必备那个小电容（通常 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>0.1</mn><mi>μ</mi><mtext>F</mtext></mrow><annotation encoding="application/x-tex">0.1\mu\text{F}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.8778em;vertical-align:-0.1944em;"></span><span class="mord">0.1</span><span class="mord mathnormal">μ</span><span class="mord text"><span class="mord">F</span></span></span></span></span>）的原因。</p>
<p>芯片工作时，它会消耗电流，而且不是稳定消耗——有时多、有时少（比如 CPU 在密集运算时电流飙升）。这种电流的剧烈波动会在电源线上产生电压波动，因为导线本身有电阻和电感。</p>
<p>这时，电源引脚旁的小电容就像一个<strong>本地水库</strong>：</p>
<ul>
<li>芯片突然多要电流 → 电容立刻放电补给，不用走远路去电源那边取</li>
<li>芯片突然少要电流 → 电容吸收多余的电流</li>
</ul>
<p>相当于电容充当了一个<strong>缓冲</strong>，把电源的波动给"压平"了。</p>
<blockquote>
<p>芯片电源引脚 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>0.1</mn><mi>μ</mi><mtext>F</mtext><mo>+</mo><mn>10</mn><mi>μ</mi><mtext>F</mtext></mrow><annotation encoding="application/x-tex">0.1\mu\text{F} + 10\mu\text{F}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.8778em;vertical-align:-0.1944em;"></span><span class="mord">0.1</span><span class="mord mathnormal">μ</span><span class="mord text"><span class="mord">F</span></span><span class="mspace" style="margin-right:0.2222em;"></span><span class="mbin">+</span><span class="mspace" style="margin-right:0.2222em;"></span></span><span class="base"><span class="strut" style="height:0.8778em;vertical-align:-0.1944em;"></span><span class="mord">10</span><span class="mord mathnormal">μ</span><span class="mord text"><span class="mord">F</span></span></span></span></span> 组合：<span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>0.1</mn><mi>μ</mi><mtext>F</mtext></mrow><annotation style="height:0.8778em;vertical-align:-0.1944em;"></span><span class="mord">10</span><span class="mord mathnormal">μ</span><span class="mord text"><span class="mord">F</span></span></span></span></span> 处理低频波动。</p>
</blockquote>
<h3>滤波</h3>
<p>交流电经整流后得到的是脉动直流——它的大方向是直流，但电压一直在波动，波形像一串连续的半圆。</p>
<p>在整流输出端并联一个足够大的电容：</p>
<ul>
<li>电压上升时，电容充电</li>
<li>电压下降时，电容放电（靠存着的电维持输出电压）</li>
</ul>
<p>结果：原本的脉动波形被"填平"成带微小波纹的平稳直流。这就是<strong>电容滤波</strong>的基本原理。</p>
<p>电容越大，能存越多电 → 放电时电压掉得越少 → 纹波越小。</p>

class="mord mathnormal mtight">t</span></span></span></span></span><span class="vlist-s">​</span></span><span class="vlist-r"><span class="vlist" </blockquote>
<p>信号先是经过电阻，然后接一个电容到地，输出从电阻和电容的中间接出来。</p>
<h3>原理</h3>
<p><strong>高频信号来的时候</strong>：</p>
<ul>
<li>电容的容抗 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><msub><mi>X</mi><mi>c</mi></msub></mrow><annotation encoding="application/x-tex">X_c</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.8333em;vertical-align:-0.15em;"></span><span class="mord"><span class="mord mathnormal" style="margin-right:0.0785em;">X</span><span class="msupsub"><span class="vlist-t vlist-t2"><span class="vlist-r"><span class="vlist" style="height:0.1514em;"><span style="top:-2.55em;margin-left:-0.0785em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mord mathnormal mtight">c</span></span></span></span><span class="vlist-s">​</span></span><span class="vlist-r"><span class="vlist" style="height:0.15em;"><span></span></span></span></span></span></span></span></span></span> 非常小（频率高 → 容抗小）</li>
<li>电容相当于把高频信号直接导到地（GND）</li>
<li>输出端几乎没有高频信号 → <strong>高频被滤掉了</strong></li>
</ul>
<p><strong>低频信号来的时候</strong>：</p>
<ul>
<li>电容的容抗 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><msub><mi>X</mi><mi>c</mi></msub></mrow><annotation encoding="application/x-tex">X_c</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.8333em;vertical-align:-0.15em;"></span><span class="mord"><span class="mord mathnormal" style="margin-right:0.0785em;">X</span><span class="msupsub"><span class="vlist-t vlist-t2"><span class="vlist-r"><span class="vlist" style="height:0.1514em;"><span style="top:-2.55em;margin-left:-0.0785em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mord mathnormal mtight">c</span></span></span></span><span class="vlist-s">​</span></span><span class="vlist-r"><span class="vlist" style="height:0.15em;"><span></span></span></span></span></span></span></span></span></span> 非常大（频率低 → 容抗大）</li>
<li>信号基本走不过电容到地，老老实实走向输出端</li>
<li>输出端低频信号完好 → <strong>低频通过</strong></li>
</ul>

<h3>应用场景</h3>
<ul>
<li><strong>音频电路</strong>：滤掉高频噪声和嘶嘶声</li>
<li><strong>ADC 输入前端</strong>：滤掉高于采样频率一半的噪声（抗混叠滤波）</li>
<li><strong>传感器信号调理</strong>：过滤环境电磁干扰</li>
<li><strong>电源去噪</strong>：滤除电源线上的高频纹波</li>
</ul>

<h3>原理</h3>
<p><strong>高频信号来的时候</strong>：</p>
<ul>
<li>电容容抗非常小，高频信号轻松穿过电容</li>
<li>到达输出端，高频信号完好 → <strong>高频通过</strong></li>
</ul>
<p><strong>低频信号来的时候</strong>：</p>
<ul>
<li>电容容抗非常大，信号很难穿过电容</li>
<li>输出端几乎收不到信号 → <strong>低频被滤掉</strong></li>
</ul>
<p>直流信号：电容相当于断路，完全通不过。</p>

<ul>
