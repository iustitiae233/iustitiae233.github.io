3c:T148c9,<h2>一、电感是什么？</h2>
<p>电感就是把导线绕成线圈——一圈一圈地绕在磁芯或骨架上。它的物理结构就是这么简单。</p>
<p>但这一绕，就绕出了一个<strong>电磁感应</strong>效应：</p>
<ul>
<li>电流通过线圈 → 产生磁场（电能变磁能）</li>
<li>磁场变化 → 在线圈中感应出电压（磁能变电能）</li>
</ul>
<blockquote>
<p>💡 <strong>通俗类比</strong>：电感就像电路里的<strong>惯性飞轮</strong>。你推飞轮让它加速，它不肯立刻加速——有一股抗力；等它转起来了，你想让它停下来，它又不肯停——继续往前冲。电感对电流的态度一模一样：不让电流突变。</p>
</blockquote>

</blockquote>

<h2>三、电感回路的电阻突然变大——会发生什么？</h2>
<p>这是电感最"凶猛"的特性，也是开关电源和点火系统的核心原理。</p>

</blockquote>
<h3>这个特性不是坏事——恰恰是很多电路的核心</h3>
<ul>
<li><strong>Boost 升压电路</strong>：故意利用这个特性。先让电流在线圈中建立起来，然后突然切断回路，电感"不肯让电流消失"，拼命在两端产生高电压把电流"推出去"，这股高压被引导到输出电容上，就实现了从低压到高压的转换。</li>
<li><strong>汽车点火系统</strong>：<span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>12</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">12\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">12</span><span class="mord text"><span class="mord">V</span></span></span></span></span> 电瓶通过点火线圈产生上万伏的高压，点燃汽油——靠的就是电感。</li>
</ul>
<h3>保护措施：续流二极管</h3>
<p>在实际电路中，如果电感回路上有开关管（三极管、MOS 管），关断时电感的反电动势会击穿开关管。解决方案是在电感两端反向并联一个二极管——让电感在关断瞬间通过二极管形成低阻抗续流回路，把磁能安全消耗掉。</p>

<h3>原理</h3>
<p><strong>低频信号</strong>：</p>
<ul>
<li>感抗小，电感相当于导线到地</li>
<li>低频信号被从电阻后面短路到地 → <strong>低频滤掉</strong></li>
</ul>
<p><strong>高频信号</strong>：</p>
<ul>
<li>感抗大，电感相当于断路</li>
<li>信号走向输出端 → <strong>高频通过</strong></li>
</ul>
<blockquote>
<p>注意 RC 和 RL 的对称性：RC 高通是 C 串联 + R 到地；RL 高通是 R 串联 + L 到地。电容在 RC 中的串联位置等同于电感在 RL 中的到地位置。</p>
</blockquote>

<h2>七、LC 低通滤波原理</h2>
<p>这是最重要的滤波器——把电感和电容组合在一起，效果远超单独的 RC 或 RL。</p>
<h3>为什么需要 LC？</h3>
<p>RC 滤波器虽然简单，但有一个致命问题：<strong>电阻本身消耗功率</strong>。在大电流场合（如电源滤波），电阻上会发热、浪费能量、降低效率。</p>
<p>而电感和电容都是<strong>储能元件</strong>，理论上是<strong>不消耗功率</strong>的——能量在电容的电场和电感的磁场之间来回转换，不变成热量。</p>

<li>电容 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>C</mi></mrow><annotation encoding="application/x-tex">C</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord mathnormal" style="margin-right:0.0715em;">C</span></span></span></span> 并联到地：低频时容抗大 → 不往地漏；高频时容抗小 → 把残余高频短路到地</li>

<p>电感堵高频 + 电容放高频到地 = <strong>双重截杀高频信号</strong>。</p>

<h3>LC 滤波的独特之处：谐振</h3>
<p>LC 滤波器在截止频率附近会发生<strong>谐振</strong>——这是纯 LC 滤波器最需要注意的问题。</p>
<p>在谐振频率处，电感的感抗和电容的容抗恰好相等，相互抵消：</p>
<ul>
<li><strong>串联 LC</strong>（L + C 串联在信号路径上）：谐振时阻抗为零，信号完全通过 → 形成<strong>带通</strong></li>
<li><strong>并联 LC</strong>（L 串联，C 并联到地）：谐振时阻抗无穷大，信号被完全堵住</li>
</ul>
<p>对于上面这种 LC 低通拓扑（L 串联 + C 到地），谐振频率恰好等于截止频率。如果信号刚好在这个频率附近，输出可能比输入还大（<strong>电压过冲</strong>）！</p>
<blockquote>
<p>🔧 实际电源电路中，常在电容上串联一个小电阻（几 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi mathvariant="normal">Ω</mi></mrow><annotation encoding="application/x-tex">\Omega</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">Ω</span></span></span></span>）来"压制"谐振，这叫阻尼。或者用更大的电容让谐振频率远低于工作频率。</p>
</blockquote>
<h3>应用场景</h3>
<ul>
<li><strong>开关电源 Buck/Boost 输出滤波</strong>：最核心的应用，把 PWM 高频方波平滑成平稳直流</li>
<li><strong>EMI 滤波</strong>：电源输入端加 LC 滤波器，阻止设备的高频噪声串入电网</li>
<li><strong>射频电路选频</strong>：利用 LC 谐振选出特定频率</li>
<li><strong>音响分频器</strong>：低音扬声器前串电感（低通），高音扬声器前串电容（高通）</li>
</ul>
