3d:T104dc,<h2>一、二极管的基本结构</h2>
<p>二极管的核心是<strong>PN 结</strong>——一块半导体上做出两种不同掺杂的区域。</p>
<h3>P 型半导体和 N 型半导体</h3>
<p>纯硅（4 价元素）本身不导电——所有电子都被共价键绑死了。</p>
<ul>
<li><strong>N 型</strong>：在硅里掺入少量 5 价元素（如磷）。多出一个自由电子——这个电子可以到处跑，所以 N 型半导体靠<strong>电子</strong>导电。</li>
<li><strong>P 型</strong>：在硅里掺入少量 3 价元素（如硼）。少了一个电子，留下一个"空穴"——相邻电子会跳过来填补这个空穴，原来的位置又形成新空穴。相当于空穴在反向移动，所以 P 型半导体靠<strong>空穴</strong>导电（等价于正电荷移动）。</li>
</ul>
<h3>PN 结的形成</h3>
<p>把 P 型和 N 型做到一起，交界面处会发生：</p>
<ol>
<li>N 区的自由电子扩散到 P 区，P 区的空穴扩散到 N 区</li>
<li>交界处 N 侧失去电子带<strong>正电</strong>，P 侧得到电子带<strong>负电</strong></li>
<li>形成一个内建电场，阻止进一步扩散</li>
<li>这个没有自由载流子的区域叫<strong>耗尽层</strong>（也叫空间电荷区）</li>
</ol>
<p>这个结构就是 PN 结——二极管的物理本质。</p>
<blockquote>
<p>💡 <strong>通俗理解</strong>：PN 结就像电路里的<strong>单向阀/止回阀</strong>。水只能从 P 往 N 方向流，反过来就会被堵死。</p>
</blockquote>
<hr>
<h2>二、单向导电性——二极管的核心功能</h2>
<h3>正向偏置（导通）</h3>
<p>P 接正极，N 接负极：</p>
<ul>
<li>外加电场削弱了内建电场</li>
<li>耗尽层变薄</li>
<li>电子从 N 区穿越 PN 结到 P 区，空穴从 P 区到 N 区</li>
<li>电流流过</li>
</ul>
<p><strong>但二极管不是随便给点正向电压就导通的</strong>。硅二极管存在一个<strong>门槛电压（导通电压）</strong>，约 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn mathvariant="bold">0.6</mn><mtext>V</mtext><mo>∼</mo><mn mathvariant="bold">0.7</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">\mathbf{0.6\text{V} \sim 0.7\text{V}}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord"><span class="mord mathbf">0.6</span><span class="mord text"><span class="mord">V</span></span><span class="mspace" style="margin-right:0.2778em;"></span><span class="mrel">∼</span><span class="mspace" style="margin-right:0.2778em;"></span><span class="mord mathbf">0.7</span><span class="mord text"><span class="mord">V</span></span></span></span></span></span>（锗管约 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>0.2</mn><mtext>V</mtext><mo>∼</mo><mn>0.3</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">0.2\text{V} \sim 0.3\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">0.2</span><span class="mord text"><span class="mord">V</span></span><span class="mspace" style="margin-right:0.2778em;"></span><span class="mrel">∼</span><span class="mspace" style="margin-right:0.2778em;"></span></span><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">0.3</span><span class="mord text"><span class="mord">V</span></span></span></span></span>）。</p>
<p>电压低于门槛值时，电流几乎为零。一旦超过门槛值，电流随电压指数级增长——微小的电压增加带来巨大的电流增加。</p>
<p>正向导通后，二极管两端的压降基本锁定在 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mo>∼</mo><mn>0.7</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">\sim 0.7\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.3669em;"></span><span class="mrel">∼</span><span class="mspace" style="margin-right:0.2778em;"></span></span><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">0.7</span><span class="mord text"><span class="mord">V</span></span></span></span></span>（硅管），不管电流多大（在额定范围内）变化都不大。</p>
<h3>反向偏置（截止）</h3>
<p>N 接正极，P 接负极：</p>
<ul>
<li>外加电场加强了内建电场</li>
<li>耗尽层变宽</li>
<li>几乎没有载流子能穿过</li>
<li>电流约等于零</li>
</ul>
<blockquote>
<p>🔑 这就是单向导电性——电流只能从 P→N（阳极→阴极），不能反向。</p>
</blockquote>
<hr>
<h2>三、漏电特性</h2>
<p>二极管反向偏置时不是绝对不导电——有微小的<strong>反向漏电流</strong>在流动。</p>
<h3>漏电流的来源</h3>
<ul>
<li><strong>少子漂移</strong>：P 区里残留的少量电子被反向电场拉过 PN 结，N 区里残留的少量空穴被拉过去。这个电流非常小。</li>
<li><strong>表面漏电</strong>：芯片表面污染、潮湿导致的沿表面漏电。</li>
<li><strong>温度效应</strong>：温度每升高约 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><msup><mn>10</mn><mo>∘</mo></msup><mtext>C</mtext></mrow><annotation encoding="application/x-tex">10^\circ\text{C}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">1</span><span class="mord"><span class="mord">0</span><span class="msupsub"><span class="vlist-t"><span class="vlist-r"><span class="vlist" style="height:0.6741em;"><span style="top:-3.063em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mbin mtight">∘</span></span></span></span></span></span></span></span><span class="mord text"><span class="mord">C</span></span></span></span></span>，反向漏电流翻一倍。</li>
</ul>

<h2>四、半波整流电路</h2>
<p>把交流电变成直流电，最简单的做法就是半波整流。</p>
<h3>电路</h3>
<blockquote>
<p>交流输入 → 二极管 D → 负载电阻 R → 回到交流另一端</p>
</blockquote>
<h3>工作原理</h3>
<p>交流电是正弦波——上半周电压为正，下半周电压为负。</p>
<ul>
<li><strong>正半周</strong>：二极管正向偏置 → 导通 → 电流流过负载 → 负载上有电压</li>
<li><strong>负半周</strong>：二极管反向偏置 → 截止 → 没有电流 → 负载上电压为 0</li>
</ul>
<p>结果：输出只有正半周的波形——像正弦波被砍掉了一半，只剩一串半圆形凸起。</p>
<h3>半波整流的特点</h3>
<table>
<thead>
<tr>
<th>优点</th>
<th>缺点</th>
</tr>
</thead>
<tbody>
<tr>
<td>电路简单，仅需一个二极管</td>
<td>浪费了一半的电能（负半周全丢了）</td>
</tr>
<tr>
<td>成本最低</td>
<td>输出电压脉动大，平均值只有峰值电压的约 <strong>31.8%</strong></td>
</tr>
<tr>
<td></td>
<td>需要很大的滤波电容才能平滑</td>
</tr>
</tbody>
</table>
<blockquote>
<p>半波整流一般只用在功率极小、对纹波要求不高的场合。</p>
</blockquote>

<h2>五、全波整流电路</h2>
<p>把交流电的两个半周都利用起来，效率翻倍。</p>
<h3>桥式全波整流（最常用）</h3>
<p>用 4 个二极管搭成一个"桥"：</p>
<pre><code class="hljs language-cpp">        D1      D2
交流 L ──┬──▶|───┬───|◀──┐
         │        │        │
         │        ├── 输出+ ──→ 负载 R
         │        │        │
交流 N ──┼──▶|───┼───|◀──┤
        D3      D4      │
         │               │
         └─── 输出- ─────┘
</code></pre>
<h3>工作原理</h3>
<p><strong>正半周</strong>（上正下负）：D1 和 D4 导通，D2 和 D3 截止。电流走 D1 → 负载 → D4。</p>
<p><strong>负半周</strong>（上负下正）：D2 和 D3 导通，D1 和 D4 截止。电流走 D3 → 负载 → D2。</p>
<p>注意：<strong>无论正半周还是负半周，流过负载的电流方向始终相同</strong>——这就是整流的核心。</p>
<h3>输出波形</h3>
<p>输出不再是"一半一半"，而是把负半周翻到了上面——一串连续的半圆形脉冲。每个交流周期变成两个直流脉冲，频率翻倍。</p>

<h2>六、二极管钳位功能</h2>
<p>钳位（Clamping），就是把信号的最高或最低电位"锁"在一个固定值上。</p>
<h3>正向钳位</h3>
<blockquote>
<p>输入 → 电容 C → 输出 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><msub><mi>V</mi><mrow><mi>o</mi><mi>u</mi><mi>t</mi></mrow></msub></mrow><annotation encoding="application/x-tex">V_{out}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.8333em;vertical-align:-0.15em;"></span><span class="mord"><span class="mord mathnormal" style="margin-right:0.2222em;">V</span><span class="msupsub"><span class="vlist-t vlist-t2"><span class="vlist-r"><span class="vlist" style="height:0.2806em;"><span style="top:-2.55em;margin-left:-0.2222em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mord mtight"><span class="mord mathnormal mtight">o</span><span class="mord mathnormal mtight">u</span><span class="mord mathnormal mtight">t</span></span></span></span></span><span class="vlist-s">​</span></span><span class="vlist-r"><span class="vlist" style="height:0.15em;"><span></span></span></span></span></span></span></span></span></span>，同时 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><msub><mi>V</mi><mrow><mi>o</mi><mi>u</mi><mi>t</mi></mrow></msub></mrow><annotation encoding="application/x-tex">V_{out}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.8333em;vertical-align:-0.15em;"></span><span class="mord"><span class="mord mathnormal" style="margin-right:0.2222em;">V</span><span class="msupsub"><span class="vlist-t vlist-t2"><span class="vlist-r"><span class="vlist" style="height:0.2806em;"><span style="top:-2.55em;margin-left:-0.2222em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mord mtight"><span class="mord mathnormal mtight">o</span><span class="mord mathnormal mtight">u</span><span class="mord mathnormal mtight">t</span></span></span></span></span><span class="vlist-s">​</span></span><span class="vlist-r"><span class="vlist" </blockquote>
<p><strong>原理</strong>：</p>
<ul>
<li>信号负半周时，二极管导通，电容被充电到信号的负峰值</li>
<li>信号正半周时，二极管截止，输出 = 输入信号 + 电容上存的电压</li>
<li>结果：整个波形被往上"抬"，最低点被钳在约 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mo>−</mo><mn>0.7</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">-0.7\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.7667em;vertical-align:-0.0833em;"></span><span class="mord">−</span><span class="mord">0.7</span><span class="mord text"><span class="mord">V</span></span></span></span></span>（二极管导通压降）</li>
</ul>
<blockquote>
<p>这个电路能把一个在 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>0</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">0\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">0</span><span class="mord text"><span class="mord">V</span></span></span></span></span> 上下振荡的交流信号整体向上平移，使最低点接近 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>0</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">0\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">0</span><span class="mord text"><span class="mord">V</span></span></span></span></span>。常用于需要单电源供电的交流放大电路。</p>
</blockquote>
<h3>反向钳位</h3>
<p>把二极管反过来（阴极朝外），就能把波形的最高点钳在 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mo>+</mo><mn>0.7</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">+0.7\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.7667em;vertical-align:-0.0833em;"></span><span class="mord">+</span><span class="mord">0.7</span><span class="mord text"><span class="mord">V</span></span></span></span></span>。</p>
<h3>应用场景</h3>
<ul>
<li><strong>ADC 输入保护</strong>：钳位二极管把输入电压限制在 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mn>0</mn><mtext>V</mtext><mo>∼</mo><msub><mi>V</mi><mrow><mi>C</mi><mi>C</mi></mrow></msub><mo>+</mo><mn>0.7</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">0\text{V} \sim V_{CC}+0.7\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">0</span><span class="mord text"><span class="mord">V</span></span><span class="mspace" style="margin-right:0.2778em;"></span><span class="mrel">∼</span><span class="mspace" style="margin-right:0.2778em;"></span></span><span class="base"><span class="strut" style="height:0.8333em;vertical-align:-0.15em;"></span><span class="mord"><span class="mord mathnormal" style="margin-right:0.2222em;">V</span><span class="msupsub"><span class="vlist-t vlist-t2"><span class="vlist-r"><span class="vlist" style="height:0.3283em;"><span style="top:-2.55em;margin-left:-0.2222em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mord mtight"><span class="mord mathnormal mtight" style="margin-right:0.0715em;">C</span><span class="mord mathnormal mtight" style="margin-right:0.0715em;">C</span></span></span></span></span><span class="vlist-s">​</span></span><span class="vlist-r"><span class="vlist" style="height:0.15em;"><span></span></span></span></span></span></span><span class="mspace" style="margin-right:0.2222em;"></span><span class="mbin">+</span><span class="mspace" style="margin-right:0.2222em;"></span></span><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">0.7</span><span class="mord text"><span class="mord">V</span></span></span></span></span> 之间，防止烧毁 ADC 引脚</li>
<li><strong>电平移位</strong>：在不失真的前提下改变信号的直流偏置</li>
<li><strong>ESD 保护</strong>：把静电放电的高压脉冲钳到安全范围</li>
</ul>

<h2>七、二极管控制电流方向——续流与防反接</h2>
<h3>续流二极管</h3>
<p>前面电感章节提过——在继电器线圈、电机、电磁阀等感性负载两端，<strong>反向并联一个二极管</strong>。</p>
<p>正常工作时，二极管反偏不导通。关断瞬间，电感产生反电动势——这个电压恰好让二极管正向导通，给电感提供一个低阻抗续流回路。电流在线圈 → 二极管 → 线圈之间循环衰减，把磁能安全消耗掉。</p>
<blockquote>
<p><strong>没有续流二极管</strong>：关断瞬间反电动势直接击穿驱动三极管 / MOS 管。</p>
</blockquote>
<h3>防反接保护</h3>
<p>把二极管串联在电源正极线上（阳极接电源，阴极接电路）：</p>
<ul>
<li>电源正接：二极管正向导通，电路正常工作（二极管上会消耗 <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mo>∼</mo><mn>0.7</mn><mtext>V</mtext></mrow><annotation encoding="application/x-tex">\sim 0.7\text{V}</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.3669em;"></span><span class="mrel">∼</span><span class="mspace" style="margin-right:0.2778em;"></span></span><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord">0.7</span><span class="mord text"><span class="mord">V</span></span></span></span></span>）</li>
<li>电源反接：二极管反向截止，电流流不过去，电路不工作也不会烧</li>
</ul>
<blockquote>
<p>大电流场合用 MOS 管代替二极管做防反接——MOS 管导通电阻毫欧级，几乎没有压降损耗。</p>
</blockquote>

<h3>关键：击穿不等于损坏！</h3>
<ul>
<li><strong>普通二极管</strong>：击穿通常意味着永久损坏（热烧毁）</li>
<li><strong>稳压二极管</strong>：专门设计在击穿区工作，它能承受击穿而不损坏（后文详解）</li>
</ul>

<h2>九、稳压二极管（齐纳二极管）</h2>
<p>把普通二极管的反向击穿这个"缺陷"，故意做成稳定可控的特性——这就是稳压二极管。</p>
<h3>基本功能</h3>
<p>稳压管<strong>反向接在电路中</strong>，工作在击穿区：</p>
<ul>
<li>当反向电压低于稳压值时，不导通（正常反向截止）</li>
<li>当反向电压达到稳压值（<span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><msub><mi>V</mi><mi>z</mi></msub></mrow><annotation encoding="application/x-tex">V_z</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.8333em;vertical-align:-0.15em;"></span><span class="mord"><span class="mord mathnormal" style="margin-right:0.2222em;">V</span><span class="msupsub"><span class="vlist-t vlist-t2"><span class="vlist-r"><span class="vlist" style="height:0.1514em;"><span style="top:-2.55em;margin-left:-0.2222em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mord mathnormal mtight" style="margin-right:0.044em;">z</span></span></span></span><span class="vlist-s">​</span></span><span class="vlist-r"><span class="vlist" style="height:0.15em;"><span></span></span></span></span></span></span></span></span></span>）时，二极管击穿导通，但<strong>不损坏</strong></li>
<li>击穿后，流过管子的电流可以在很大范围内变化，而两端电压<strong>保持不变</strong>（<span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mo>≈</mo><msub><mi>V</mi><mi>z</mi></msub></mrow><annotation encoding="application/x-tex">\approx V_z</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.4831em;"></span><span class="mrel">≈</span><span class="mspace" style="margin-right:0.2778em;"></span></span><span class="base"><span class="strut" style="height:0.8333em;vertical-align:-0.15em;"></span><span class="mord"><span class="mord mathnormal" style="margin-right:0.2222em;">V</span><span class="msupsub"><span class="vlist-t vlist-t2"><span class="vlist-r"><span class="vlist" style="height:0.1514em;"><span style="top:-2.55em;margin-left:-0.2222em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mord mathnormal mtight" style="margin-right:0.044em;">z</span></span></span></span><span class="vlist-s">​</span></span><span class="vlist-r"><span class="vlist" style="height:0.15em;"><span></span></span></span></span></span></span></span></span></span>）</li>

<h3>稳压管 vs LDO（线性稳压器）</h3>
<table>
<thead>
<tr>
<th></th>
<th>稳压二极管</th>
<th>LDO (如 AMS1117)</th>
</tr>
</thead>
<tbody>
<tr>
<td>精度</td>
<td>一般（5%~10%）</td>
<td>很高（1%~2%）</td>
</tr>
<tr>
<td>输出电流</td>
<td>小（mA 级）</td>
<td>大（几百 mA ~ 几 A）</td>
</tr>
<tr>
<td>电路复杂度</td>
<td>极简（一个电阻 + 一个管子）</td>
<td>需要输入输出电容</td>
</tr>
<tr>
<td>适用场景</td>
<td>参考电压、简易稳压</td>
<td>芯片供电、大电流供电</td>
</tr>
</tbody>
</table>
<blockquote>
<p>稳压管适合给运放提供参考电压、给 MOS 管栅极做钳位保护、简易的过压保护电路。给芯片供电还是用 LDO。</p>
</blockquote>
