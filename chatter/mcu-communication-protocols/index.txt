34:T2082,<h2>引言</h2>
<p>在嵌入式系统中，通信协议是各模块之间对话的语言。UART、I2C 和 SPI 是最常用的三种串行通信协议——它们各自有着鲜明的性格特点，适用的场景也截然不同。理解它们的差异，是选择正确协议的前提。</p>
<h2>一、UART —— 异步通信的经典</h2>
<h3>基本原理</h3>
<p>UART（Universal Asynchronous Receiver/Transmitter）是一种<strong>异步、全双工、点对点</strong>的串行通信协议。它不需要共享时钟信号，通信双方通过<strong>预先约定相同的波特率</strong>来同步。</p>
<h3>硬件连接</h3>
<ul>
<li><strong>最少 2 根线</strong>：TX（发送）、RX（接收）</li>
<li>可选硬件流控：RTS、CTS</li>
</ul>
<h3>数据帧格式</h3>
<pre><code class="hljs language-cpp">┌─────────┬──────────────────┬──────────┬──────────┐
│ 起始位   │  数据位(<span class="hljs-number">5</span>~<span class="hljs-number">9</span>位)   │  校验位   │  停止位   │
│  (<span class="hljs-number">1</span>位)   │   (通常<span class="hljs-number">8</span>位)      │  (可选)   │ (<span class="hljs-number">1</span>/<span class="hljs-number">2</span>位)  │
└─────────┴──────────────────┴──────────┴──────────┘
</code></pre>
<ul>
<li><strong>起始位</strong>：数据线从高拉低，通知接收方开始传输</li>
<li><strong>数据位</strong>：5~9 位（通常 8 位），LSB 先发</li>
<li><strong>奇偶校验位</strong>：可选，用于错误检测</li>
<li><strong>停止位</strong>：将数据线拉高，持续 1 位或 2 位时间</li>
</ul>
<h3>优缺点</h3>
<p>优点缺点仅需 2 根线，简单易用仅支持点对点通信无需时钟信号数据帧最大 9 位有奇偶校验位两端波特率偏差不能超过约 10%可扩展为 RS-232/RS-485速度较慢（通常 ≤ 115200 bps）</p>
<h2>二、I²C —— 多设备总线的优雅</h2>
<h3>基本原理</h3>
<p>I²C（Inter-Integrated Circuit）是一种<strong>同步、半双工、多主多从</strong>的串行通信协议。它通过<strong>地址寻址</strong>方式选择通信目标设备。</p>
<h3>硬件连接</h3>
<ul>
<li><strong>仅 2 根线</strong>：SDA（数据）、SCL（时钟）</li>
<li>两条线都需要<strong>上拉电阻</strong>（通常 4.7KΩ）</li>
<li>总线为<strong>开漏输出</strong>设计，支持多设备共享</li>
</ul>
<h3>通信时序</h3>
<pre><code class="hljs language-cpp">┌──────────────────────────────────────────────────────────────┐
│ 起始条件 │ 从机地址(<span class="hljs-number">7</span>/<span class="hljs-number">10</span>位)+R/W位 │ ACK │ 数据帧 │ ACK │ ... │ 停止条件 │
└──────────────────────────────────────────────────────────────┘
</code></pre>
<ul>
<li><strong>起始条件</strong>：SCL 高电平时，SDA 由高→低</li>
<li><strong>停止条件</strong>：SCL 高电平时，SDA 由低→高</li>
<li><strong>地址帧</strong>：7 位或 10 位从机地址 + 1 位读写位</li>
<li><strong>ACK/NACK</strong>：接收方拉低 SDA 表示确认</li>
</ul>
<h3>优缺点</h3>
<p>优点缺点仅需 2 根线速度比 SPI 慢支持多主多从架构数据帧固定 8 位内置 ACK/NACK 确认协议复杂度较高地址寻址，节省 GPIO通信距离短（通常板内）</p>
<h2>三、SPI —— 高速通信的王者</h2>
<h3>基本原理</h3>
<p>SPI（Serial Peripheral Interface）是一种<strong>同步、全双工、主从架构</strong>的串行通信协议。它通过**片选信号（CS）**来选择通信目标。</p>
<h3>硬件连接</h3>
<ul>
<li><strong>4 根线</strong>：</li>
<li><strong>SCLK/SCK</strong>：时钟线（主机产生）</li>
<li><strong>MOSI</strong>：主机输出、从机输入</li>
<li><strong>MISO</strong>：主机输入、从机输出</li>
<li><strong>SS/CS</strong>：片选信号（每个从机一条独立线）</li>
</ul>
<h3>4 种工作模式</h3>
<p>模式CPOLCPHA说明模式 000空闲时钟低，第一个边沿采样（最常用）模式 101空闲时钟低，第二个边沿采样模式 210空闲时钟高，第一个边沿采样模式 311空闲时钟高，第二个边沿采样</p>
<h3>传输过程</h3>
<ol>
<li>主机输出时钟信号</li>
<li>主机<strong>拉低目标从机的 CS 引脚</strong>，激活从机</li>
<li>主机通过 MOSI 发送数据，同时从机通过 MISO 返回数据（全双工）</li>
<li>传输完成后，主机<strong>拉高 CS</strong> 释放从机</li>
</ol>
<h3>优缺点</h3>
<p>优点缺点速度最快（10~50 MHz）需要 4 根线，每增加从机多一根 CS全双工，可同时收发无内置错误检测和确认机制无起始/停止位，数据可连续流不支持多主机协议简单无标准协议层</p>
<h2>四、三大协议全面对比</h2>
<p>特性<strong>UARTI²CSPI通信方式</strong>异步同步同步<strong>双工模式</strong>全双工半双工全双工<strong>信号线数</strong>2 根2 根4 根<strong>拓扑结构</strong>点对点多主多从单主多从<strong>设备选择</strong>无（仅一对）地址寻址片选信号 CS<strong>典型速率</strong>9.6K<del>115.2K bps100K/400K/3.4M bps10M</del>50M bps<strong>数据帧大小</strong>5~9 位固定 8 位无限制（连续传输）<strong>错误检测</strong>奇偶校验位ACK/NACK无内置<strong>通信距离</strong>较长（RS-485 可达千米）短（板内 &#x3C;1m）短（&#x3C;0.5m）<strong>复杂度</strong>中等较高简单</p>
<h2>五、选型指南 —— 什么时候选谁？</h2>
<h3>🟢 选 UART 的场景</h3>
<ul>
<li><strong>调试与日志输出</strong>：嵌入式开发中最常用的调试手段</li>
<li><strong>PC 与 MCU 通信</strong>：通过 USB 转串口连接</li>
<li><strong>GPS/GSM/蓝牙模块</strong>：点对点无线通信模块</li>
<li><strong>工业远距离通信</strong>：配合 RS-232/RS-485 电平转换</li>
</ul>
<h3>🔵 选 I²C 的场景</h3>
<ul>
<li><strong>多传感器网络</strong>：温湿度传感器（SHT30）、气压传感器（BMP280）</li>
<li><strong>EEPROM 存储</strong>：AT24Cxx 系列</li>
<li><strong>RTC 实时时钟</strong>：DS3231、PCF8563</li>
<li><strong>GPIO 扩展/ADC/DAC</strong>：需要节省引脚资源</li>
<li><strong>OLED 小屏幕</strong>：SSD1306 等</li>
</ul>
<h3>🔴 选 SPI 的场景</h3>
<ul>
<li><strong>高速数据存储</strong>：NOR Flash（W25Qxx）、SD 卡</li>
<li><strong>TFT 彩屏驱动</strong>：ST7789、ILI9341</li>
<li><strong>高速 ADC/DAC</strong>：音频采集、高速采样</li>
<li><strong>WiFi 模块</strong>：部分高速无线模块</li>
</ul>
<h2>六、总结口诀</h2>
<pre><code class="hljs language-cpp">速度排名：  SPI  >>  I²C  >  UART
引脚数量：  <span class="hljs-built_in">SPI</span>(<span class="hljs-number">4</span>+) >  <span class="hljs-built_in">UART</span>(<span class="hljs-number">2</span>~<span class="hljs-number">4</span>)  >  I²<span class="hljs-built_in">C</span>(<span class="hljs-number">2</span>)
设备扩展：  I²<span class="hljs-built_in">C</span>(地址寻址)  >  <span class="hljs-built_in">SPI</span>(片选)  >  <span class="hljs-built_in">UART</span>(仅点对点)
协议复杂度：I²C  >  UART  >  SPI
通信距离：  <span class="hljs-built_in">UART</span>(远)  >>  I²<span class="hljs-built_in">C</span>(短)  ≈  <span class="hljs-built_in">SPI</span>(短)
可靠性：   I²<span class="hljs-built_in">C</span>(ACK)  >  <span class="hljs-built_in">UART</span>(校验)  >  <span class="hljs-built_in">SPI</span>(无内置)
</code></pre>
<blockquote>
<p>没有最好的协议，只有最合适的协议。在实际项目中，三种协议往往是<strong>配合使用</strong>的——用 UART 调试通信，用 I²C 挂载传感器，用 SPI 驱动屏幕和存储。各取所长，才是正道。</p>
