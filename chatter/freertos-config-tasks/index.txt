34:T27bb,<h2>引言</h2>
<p>当你的嵌入式项目从"点个灯"进化到"同时处理显示屏刷新、传感器数据采集、WiFi通信和用户交互"时，裸机编程的超级循环（Super Loop）就捉襟见肘了。</p>
<p>FreeRTOS 是一个轻量级的实时操作系统内核，它为单片机提供了<strong>多任务调度</strong>的能力——让多个任务看起来"同时运行"。而这一切的核心，就是任务管理。</p>
<h2>一、为什么需要 RTOS？</h2>
<h3>裸机编程的痛点</h3>
<pre><code class="hljs language-cpp"><span class="hljs-keyword">while</span> (<span class="hljs-number">1</span>) {
    <span class="hljs-built_in">ReadSensor</span>();      <span class="hljs-comment">// 耗时 50ms</span>
    <span class="hljs-built_in">UpdateDisplay</span>();   <span class="hljs-comment">// 耗时 100ms</span>
    <span class="hljs-built_in">CheckButton</span>();     <span class="hljs-comment">// 必须快速响应，但被前面的任务阻塞了！</span>
    <span class="hljs-built_in">SendDataToCloud</span>(); <span class="hljs-comment">// 传输不稳定</span>
}
</code></pre>
<p>当 <code>CheckButton()</code> 需要实时响应，却因为前面的任务耗时太长而无法及时执行时，用户体验就变成了"按了键没反应"。</p>
<h3>RTOS 的解决方案</h3>
<p>FreeRTOS 通过<strong>任务调度器</strong>在多个任务之间快速切换（通常每 1ms 一次），让每个任务都能按时得到 CPU 时间。从宏观上看，所有任务在"同时"运行。</p>
<h2>二、环境搭建与基础配置</h2>
<h3>CubeMX 配置步骤</h3>
<ol>
<li>在 <strong>Middleware → FREERTOS</strong> 中，Interface 选择 <code>CMSIS_V1</code> 或 <code>CMSIS_V2</code></li>
<li>在 <strong>Tasks and Queues</strong> 选项卡中创建任务</li>
<li>在 <strong>Config parameters</strong> 中调整内核参数</li>
</ol>
<h3>关键配置宏（FreeRTOSConfig.h）</h3>
<p>配置项说明推荐值<code>configUSE_PREEMPTION</code>启用抢占式调度1（启用）<code>configTICK_RATE_HZ</code>系统时钟节拍频率1000（1ms 一个 tick）<code>configMAX_PRIORITIES</code>最大优先级数5~7（视需求而定）<code>configMINIMAL_STACK_SIZE</code>最小任务栈大小128（字）<code>configTOTAL_HEAP_SIZE</code>系统堆总大小根据任务数量和栈大小计算<code>configUSE_COUNTING_SEMAPHORES</code>启用计数信号量1<code>configUSE_MUTEXES</code>启用互斥锁1</p>
<h2>三、任务（Task）—— FreeRTOS 的核心</h2>
<h3>3.1 任务是什么？</h3>
<p>任务是 FreeRTOS 中的基本执行单元。每个任务有自己的栈空间、优先级和任务控制块（TCB）。调度器根据优先级和状态决定哪个任务获得 CPU。</p>
<h3>3.2 任务状态转换</h3>
<pre><code class="hljs language-cpp">         ┌──────────────────────┐
         │      就绪态          │ ← 任务准备好，等待 CPU
         │     (Ready)          │
         └──┬────────▲─────────┘
            │ 获得CPU │ 时间片耗尽
            ▼         │
         ┌────────────┴──────┐
         │      运行态        │ → 正在使用 CPU
         │    (Running)       │
         └────────┬──────────┘
                  │ 调用 vTaskDelay / 等待信号量 / 等待队列
                  ▼
         ┌──────────────────────┐
         │      阻塞态          │ → 等待某个事件（时间/信号量/队列）
         │    (Blocked)         │
         └──────────┬───────────┘
                    │ 事件发生（时间到/信号量获得/数据到达）
                    ▼
         ┌──────────────────────┐
         │      就绪态          │
         └──────────────────────┘
</code></pre>
<p>此外还有<strong>挂起态（Suspended）</strong>——任务被 <code>vTaskSuspend()</code> 挂起后，不参与调度，直到被 <code>vTaskResume()</code> 恢复。</p>
<h3>3.3 创建任务</h3>
<pre><code class="hljs language-cpp"><span class="hljs-comment">// 动态创建任务（推荐）</span>
<span class="hljs-function">BaseType_t <span class="hljs-title">xTaskCreate</span><span class="hljs-params">(
    TaskFunction_t pvTaskCode,    <span class="hljs-comment">// 任务函数指针</span>
    <span class="hljs-type">const</span> <span class="hljs-type">char</span> *pcName,           <span class="hljs-comment">// 任务名称（调试用）</span>
    <span class="hljs-type">uint32_t</span> usStackDepth,        <span class="hljs-comment">// 栈大小（字，不是字节！）</span>
    <span class="hljs-type">void</span> *pvParameters,           <span class="hljs-comment">// 传递给任务的参数</span>
    UBaseType_t uxPriority,       <span class="hljs-comment">// 优先级（数值越大优先级越高）</span>
    TaskHandle_t *pxCreatedTask   <span class="hljs-comment">// 任务句柄（可为 NULL）</span>
)</span></span>;

<span class="hljs-comment">// 任务函数模板</span>
<span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">MyTask</span><span class="hljs-params">(<span class="hljs-type">void</span> *pvParameters)</span> </span>{
    <span class="hljs-keyword">for</span> (;;) {  <span class="hljs-comment">// 任务函数必须有死循环！不能 return！</span>
        <span class="hljs-comment">// 任务逻辑</span>
        <span class="hljs-built_in">vTaskDelay</span>(<span class="hljs-built_in">pdMS_TO_TICKS</span>(<span class="hljs-number">1000</span>));  <span class="hljs-comment">// 延时 1000ms（以 tick 为单位）</span>
    }
}
</code></pre>
<blockquote>
<p>⚠️ <strong>重要</strong>：<code>vTaskDelay(pdMS_TO_TICKS(1000))</code> 让任务进入阻塞态 1000ms，释放 CPU 给其他任务。不要用 <code>for</code> 循环做忙等待！</p>
</blockquote>
<h3>3.4 完整示例</h3>
<pre><code class="hljs language-cpp"><span class="hljs-comment">// 任务1：LED 闪烁</span>
<span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">TaskLED</span><span class="hljs-params">(<span class="hljs-type">void</span> *pvParameters)</span> </span>{
    <span class="hljs-keyword">for</span> (;;) {
        <span class="hljs-built_in">HAL_GPIO_TogglePin</span>(LED_GPIO_Port, LED_Pin);
        <span class="hljs-built_in">vTaskDelay</span>(<span class="hljs-built_in">pdMS_TO_TICKS</span>(<span class="hljs-number">500</span>));  <span class="hljs-comment">// 500ms 闪烁</span>
    }
}

<span class="hljs-comment">// 任务2：串口打印</span>
<span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">TaskPrint</span><span class="hljs-params">(<span class="hljs-type">void</span> *pvParameters)</span> </span>{
    <span class="hljs-keyword">for</span> (;;) {
        <span class="hljs-built_in">printf</span>(<span class="hljs-string">"Hello from FreeRTOS!\r\n"</span>);
        <span class="hljs-built_in">vTaskDelay</span>(<span class="hljs-built_in">pdMS_TO_TICKS</span>(<span class="hljs-number">2000</span>));  <span class="hljs-comment">// 每 2 秒打印一次</span>
    }
}

<span class="hljs-comment">// 主函数中创建任务</span>
<span class="hljs-built_in">xTaskCreate</span>(TaskLED,   <span class="hljs-string">"LED"</span>,   <span class="hljs-number">128</span>, <span class="hljs-literal">NULL</span>, <span class="hljs-number">1</span>, <span class="hljs-literal">NULL</span>);
<span class="hljs-built_in">xTaskCreate</span>(TaskPrint, <span class="hljs-string">"Print"</span>, <span class="hljs-number">256</span>, <span class="hljs-literal">NULL</span>, <span class="hljs-number">2</span>, <span class="hljs-literal">NULL</span>);

<span class="hljs-comment">// 启动调度器</span>
<span class="hljs-built_in">vTaskStartScheduler</span>();

<span class="hljs-comment">// 调度器启动后，以下代码永远不会执行</span>
<span class="hljs-keyword">while</span> (<span class="hljs-number">1</span>) {}
</code></pre>
<h2>四、任务优先级与调度</h2>
<h3>抢占式调度</h3>
<ul>
<li><strong>高优先级任务就绪时，立即抢占低优先级任务</strong></li>
<li>相同优先级的任务通过<strong>时间片轮转</strong>（每个 tick 切换一次）</li>
<li>优先级数值越大，优先级越高（在 STM32 CubeMX 配置中）</li>
</ul>
<h3>优先级分配建议</h3>
<p>任务类型推荐优先级说明时间关键（电机控制、PID）高（4<del>5）不能被长时间阻塞用户交互（按键、显示刷新）中（2</del>3）需要及时响应后台任务（日志、数据上报）低（0~1）空闲时处理</p>
<h2>五、idle 任务与空闲钩子</h2>
<p>FreeRTOS 会自动创建一个<strong>最低优先级的 idle 任务</strong>，当所有任务都阻塞时运行。</p>
<p>可以通过<strong>空闲钩子函数</strong>在 idle 任务中执行低优先级后台操作：</p>
<pre><code class="hljs language-cpp"><span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">vApplicationIdleHook</span><span class="hljs-params">(<span class="hljs-type">void</span>)</span> </span>{
    <span class="hljs-comment">// 进入低功耗模式</span>
    <span class="hljs-comment">// 清理资源</span>
    <span class="hljs-comment">// 注意：不能在此函数中调用阻塞 API！</span>
}
</code></pre>
