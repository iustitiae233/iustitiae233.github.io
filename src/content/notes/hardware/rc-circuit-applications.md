一个电阻加一个电容，几乎是电子学里最廉价的两个元件，却能组合出**八种完全不同的功能**。本篇按作用逐个整理，每个都配电路图与适用场景。

电容本身的脾气见 [[capacitor-basics]]——"隔直通交、电压不能突变"是这八种作用共同的根。

## 一、RC 电路的作用总览

答：**滤波、延时/定时、积分电路、微分电路、阻容降压、偏置/限流、消抖和耦合隔直。**

| # | 作用 | 一句话本质 | 典型场景 |
|---|---|---|---|
| ① | 滤波 | 电容把高频杂波引到地 | 电源滤波、信号滤波 |
| ② | 延时/定时 | 电容充放电需要时间 | 复位电路、定时触发 |
| ③ | 积分 | 电容把电流"攒"成电压 | 方波变三角波、斜率控制 |
| ④ | 微分 | 电容只让变化的部分通过 | 取边沿触发信号 |
| ⑤ | 阻容降压 | 电容的容抗替代变压器限流 | 小功率低成本供电 |
| ⑥ | 偏置/限流 | 电阻定工作点、限电流 | 三极管偏置、LED 限流 |
| ⑦ | 消抖 | 电容把抖动"抹平" | 按键输入 |
| ⑧ | 耦合隔直 | 电容隔直流、传交流 | 级间信号传递 |

## 二、① 滤波（最常用）

![[rc-filters.png|RC 低频滤波电路、Π 型 RC 低频滤波电路和 RC 高频滤波电路三种电路图]]

*图：左 RC 低通（R 串联 + C 到地）；中 Π 型 RC 低通（两级 RC，C1、C2 分别对地）；右 RC 高通（C 串联 + R 到地）*

| 项 | 内容 |
|---|---|
| 作用 | 滤杂波、去毛刺、平滑电压 |
| 场景 | 电源滤波、信号滤波 |

![[rc-filters-poster.webp|海报版 RC 滤波电路图：Π 型 RC 低通、RC 高通与 RC 低通三种]]

*图：三条并排——Π 型 RC 低通（C1、C2 对地）、RC 高通（C 串联，R 到地）、RC 低通（C 到地）*

> 💡 低通与高通的分界只看**电容在哪**：电容**到地**就是把高频短路掉（低通），电容**串联**就是把低频挡住（高通）。

## 三、② 延时 / 定时

![[rc-reset-delay.png|利用 RC 充放电做延时的复位电路图：VCC 经 Rpu 接 Reset，电容到地并带按键]]

*图：VCC 经上拉电阻 Rpu 引到 Reset 与按键一端，电容并在 Reset 对地——上电时电容充电使 Reset 缓慢升到高电平*

| 项 | 内容 |
|---|---|
| 作用 | 利用电容充放电做延时 |
| 场景 | 复位电路、按键消抖、定时触发 |

> ⚠️ ②延时与 ⑦消抖用的是**同一个拓扑**（上拉电阻 + 电容 + 按键），区别只在意图：延时利用它"升得慢"的一面，消抖利用它"把抖动抹平"的一面。

## 四、③ 积分电路

![[rc-integrator.png|积分运算放大电路图：输入经 R1 接反相端，反馈回路用电容 C1，输出为输入积分]]

*图：运放反相端经 R1 接 Vin，反馈支路是电容 C1，同相端接地*

$$V_{out} = -\frac{1}{R_1C_1}\int V_{in}\,dt = -\frac{1}{\tau}\int V_{in}\,dt$$

| 项 | 内容 |
|---|---|
| 作用 | 把方波变三角波 |
| 场景 | 波形整形、斜率控制 |

## 五、④ 微分电路

![[rc-differentiator.png|微分运算放大电路图：输入经 C1 接反相端，反馈用电阻 R2，输出为输入微分]]

*图：运放反相端经电容 C1 接 Vin，反馈支路是电阻 R2——与积分电路恰好把 R、C 互换*

$$V_{out} = -R_2 \cdot C_1 \frac{dV_{in}}{dt}$$

| 项 | 内容 |
|---|---|
| 作用 | 方波变尖脉冲 |
| 场景 | 取上升/下降沿触发信号 |

> 💡 积分与微分是一对**互换 R、C 位置**的电路：电容在反馈支路上是积分，电容在输入支路上是微分。电容的位置决定它"攒"的是输出还是输入。

## 六、⑤ 阻容降压

![[rc-dropper.png|阻容降压供电电路图：AC 输入经并联电容降压、桥式整流、稳压管稳压、电容滤波后接负载]]

*图：AC 源 →（阻容降压：电容并联在输入回路）→（整流：桥式整流）→（稳压：齐纳二极管）→（滤波：电容）→ 负载*

| 项 | 内容 |
|---|---|
| 作用 | 小功率低成本降压供电 |
| 特点 | 用电容的容抗限流替代变压器，结构简单、成本极低，但**不隔离、输出电流小** |

> ⚠️ 阻容降压的整条链路是"**降压 → 整流 → 稳压 → 滤波**"四段——它跟正规开关电源的差别在于前段，后三段其实是通用的。整流与滤波的细节见 [[rectifier-and-filtering]]。

## 七、⑥ 偏置、限流

![[rc-bias-networks.png|三极管固定偏置电路、分压式偏置电路和集电极-基极负反馈偏置电路三种电路图]]

*图：左「固定偏置」——Rb 从 VCC 到基极；中「分压式偏置」——Rb1/Rb2 分压定基极，Re 接发射极；右「集电极-基极负反馈偏置」——Rb 跨接集电极与基极*

| 项 | 内容 |
|---|---|
| 作用 | 三极管偏置、LED 限流、保护 IO 口 |
| 三种偏置 | 固定偏置（简单但工作点不稳）、分压式偏置（Rb1/Rb2 分压，工程最常用）、集电极-基极负反馈偏置（Rb 跨接 C-B，自动稳工作点） |

三极管本身的原理见 [[transistor-basics]]。

## 八、⑦ 消抖电路

![[rc-debounce.png|RC 按键消抖电路图：VCC 经 Rpu 接芯片 IO，电容对地并在按键两端]]

*图：VCC 经上拉电阻 Rpu 接到芯片 IO 口，按键一端接 IO、另一端接地，电容并在按键两端*

| 项 | 内容 |
|---|---|
| 作用 | 按键按下抖动，RC 稳住电平 |
| 原理 | 机械触点闭合瞬间会产生毫秒级抖动，电容把这串快跳变积分成缓慢变化，IO 口读到的就是一个干净的电平跳变 |

> ⚠️ 消抖电容不能太大：太大则电容充满/放完的时间变长，快速连按会被"吃掉"，通常与软件的延时确认配合使用。

## 九、⑧ 耦合隔直

![[rc-coupling.png|RC 耦合隔直电路图：电容串联在信号通路中，输出经电阻到地]]

*图：输入经电容串联到输出节点，输出节点再接电阻到地——电容传递交流、隔断直流*

| 项 | 内容 |
|---|---|
| 作用 | 隔断直流、只传交流信号 |
| 场景 | 前后级直流工作点不同，又要传递信号时 |

这正是 [[capacitor-selection-and-roles]] 里"耦合电容"的用法——**串在信号通路中间**，是它区别于去耦、旁路的唯一判据。

## 小结

| 作用 | 关键元件位置 | 记忆点 |
|---|---|---|
| 滤波 | C 到地 / C 串联 | 电容管高频去向 |
| 延时、消抖 | R 上拉 + C 到地 | 同一拓扑，两种意图 |
| 积分 | C 在反馈支路 | 方波 → 三角波 |
| 微分 | C 在输入支路 | 方波 → 尖脉冲 |
| 阻容降压 | C 串在 AC 回路 | 容抗限流替代变压器 |
| 偏置、限流 | R 定工作点 | 与 C 无关的那半边 |
| 耦合隔直 | C 串在信号通路 | 隔直流、传交流 |

*RC 电路的美感在于——它做的每一件事，都只是**让电容充放电需要一点时间**这一个物理事实的不同侧面：慢，所以能滤波、能延时、能消抖；而"变化的快慢"本身，又正好被微分电路拿来当信号。*
