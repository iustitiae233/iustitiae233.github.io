把 [[rc-circuit-applications]] 里的电容换成电感，得到的就是 RL 电路——但它的脾气截然不同：**电容守电压，电感守电流**。这让 RL 电路在"抗浪涌、消尖峰"这类场合成了主角。

电感的脾气见 [[inductor-basics]]：电流不能突变，$X_L = 2\pi fL$。

## 一、RL 电路的作用总览

答：**滤波、延时、分压限流、耦合隔直、消尖峰和振荡整形。**

| # | 作用 | 本质 | 记忆点 |
|---|---|---|---|
| ① | 滤波 | 感抗随频率升高而增大 | 电感挡高频 |
| ② | 延时 | 电感电流不能突变 | 电流"爬坡"需要时间 |
| ③ | 分压限流 | 串联电感按量比分配电压 | 抑制冲击电流 |
| ④ | 耦合隔直 | 直流不能穿越磁场耦合 | 变压器原理 |
| ⑤ | 消尖峰 | 断电时电感释放磁场能 | **RL 电路最不可替代的作用** |
| ⑥ | 振荡整形 | 回路能量交替变化 | 简易振荡与波形修整 |

## 二、① 滤波：滤除杂波、平滑电压

### 低通

![[rl-lowpass.png|RL 一阶低频滤波电路与 RL 二阶低频滤波电路图：电感串联、电阻对地取输出]]

*图：左「RL 一阶低通」——L1 串联、R1 对地，输出取自 R1 两端；右「RL 二阶低通」——L1、L2 两级串联，每级各有一个 R 对地*

### 高通

![[rl-highpass.png|RL 一阶高频滤波电路与 RL 二阶高频滤波电路图：电阻串联、电感对地取输出]]

*图：左「RL 一阶高通」——R1 串联、L1 对地；右「RL 二阶高通」——R1、R2 两级串联，每级各有一个 L 对地*

### 截止频率

当 $L_1 = L_2 = L$、$R_1 = R_2 = R$ 时：

$$f_c = \frac{R}{2\pi L}$$

| 类型 | 特点 | 衰减斜率 |
|---|---|---|
| RL 一阶低通 | 留存低频信号，阻隔高频干扰 | −20 dB/十倍频 |
| RL 二阶低通 | 滤波效果更强 | −40 dB/十倍频 |

![[rl-filters-poster.webp|海报版 RL 滤波电路图：一阶低通、二阶低通、一阶高通与二阶高通四种]]

*图：四条并排——RL 一阶低通（L1 串联，R1 对地）、RL 二阶低通（L1 L2 + R1 R2）、RL 一阶高通（R1 串联，L1 对地）、RL 二阶高通（R1 R2 + L1 L2）*

> 💡 与 RC 滤波对读：RC 低通靠**电容把高频引到地**，RL 低通靠**电感把高频挡在门外**——一个"泄放"、一个"阻挡"，结果相同、功耗与场合不同。

## 三、② 延时：利用充放电实现时序延迟

![[rl-delay.png|基础 RL 延时、开关控制型电感延时和三极管驱动 RL 延时三种电路图]]

*图：左「基础 RL 延时」——VCC 经 L 到 R 对地，输出取自 R；中「开关控制型」——VCC 经开关再串 L、R；右「三极管驱动」——VCC 经 L 到三极管集电极，Rc 引出输出*

| 类型 | 原理 |
|---|---|
| 基础 RL 延时 | 电感通电能储、断电释能，电流渐变实现电平延时变化 |
| 开关控制型电感延时 | 开关通断瞬间，电感阻碍电流突变，产生时序延迟 |
| 三极管驱动 RL 延时 | 输入电平切换，电感电流缓慢升降，达成延时效果 |

## 四、③ 分压限流：分配电压、限制回路电流

![[rl-divider-limit.png|电感串联分压、电感串联限流和 RL 分压限流通用三种电路图]]

*图：左「电感串联分压」——L1 与 L2 串联，中间节点为分压点；中「电感串联限流」——电感串在负载前面；右「RL 分压限流通用」——L 与 R 串联*

| 类型 | 原理 |
|---|---|
| 电感串联分压 | 串联电感按电感量配比分配电压，阻碍电流突变 |
| 电感串联限流 | 电感阻碍电流急剧增大，起到限流保护作用 |
| RL 分压限流通用 | L 与 R 串联，共同分压，同时电感抑制冲击电流 |

## 五、④ 耦合隔直：隔断直流，传递交流信号

![[rl-coupling.png|基础互感耦合隔直电路与串联电感隔直流电路图]]

*图：左「基础互感耦合隔直」——两组线圈耦合，输入 Vi 在一侧、输出 Vo 在另一侧，无电气连接；右「串联电感隔直流」——Vi 经电感 L 后串负载，Vo 从电感与负载之间的节点引出*

| 类型 | 原理 |
|---|---|
| 基础互感耦合隔直 | 直流无法穿越磁场耦合，交流感应传递，隔断直流、通交流 |
| 串联电感隔直流 | 直流稳态电感等效短路，直流分量被阻断滞留前端，交流正常向后传输 |

> 💡 互感耦合隔直就是**变压器**的原理——两侧没有一根导线相连，信号却完整传了过去。这是"隔直"最彻底的一种做法，也是 [[capacitor-selection-and-roles]] 里耦合电容所做不到的**电气隔离**。

## 六、⑤ 消尖峰：吸收电压浪涌、保护器件

![[rl-snubber.png|续流泄放型、RL 缓冲吸收电路和并联电感钳位消峰三种保护电路图]]

*图：左「续流泄放型」——继电器线圈并在三极管集电极，二极管跨接线圈两端做续流；中「RL 缓冲吸收」——负载电感 L 并联电阻 R 构成 RL 缓冲；右「并联电感钳位消峰」——信号端与主回路之间串入电感做钳位吸收*

| 类型 | 原理 |
|---|---|
| 续流泄放型 | 电感断电产生反向高压尖峰，经二极管回路泄放，钳位电压保护器件 |
| RL 缓冲吸收电路 | 负载电感并联电阻构成 RL 缓冲，泄放断电感应尖峰，抑制电压浪涌 |
| 并联电感钳位消峰 | 瞬时尖峰被电感储能吸收，平缓电压波形 |

> ⚠️ 这是 RL 电路里**最不可省略**的一种用法：继电器、电机、电磁阀这类感性负载，断电瞬间 $U = L\frac{di}{dt}$ 会冲出远高于电源的尖峰，足以打穿驱动三极管。没有续流二极管，电路第一次断电就可能失效。

## 七、⑥ 振荡整形：构成简易振荡、波形修整电路

![[rl-oscillator.png|RL 振荡电路（开关控制）与 RL 波形整形电路图]]

*图：左「RL 振荡电路（开关控制）」——VCC 经 L 到三极管集电极，R 接发射极，Io 控制基极；右「RL 波形整形电路」——Vi 经 L 串联 R 对地，输出取自 R*

| 类型 | 原理 |
|---|---|
| RL 振荡电路（开关控制） | 三极管通断改变 LR 回路状态，电感储能释能形成振荡波形 |
| RL 波形整形电路 | 利用电感电流滞后特性，畸变波形修整平滑，RL 回路能量交替变化产生振荡信号 |

## 小结

| 作用 | 关键结构 | 记忆点 |
|---|---|---|
| 滤波 | L 串联为低通 / L 对地为高通 | $f_c = \dfrac{R}{2\pi L}$ |
| 延时 | L 串在供电回路 | 电流爬坡需要时间 |
| 分压限流 | 两电感串联 / L 串负载 | 抑制冲击电流 |
| 耦合隔直 | 互感耦合 / L 串联 | 互感可做电气隔离 |
| **消尖峰** | 二极管续流 / R 并 L / L 串联钳位 | 断电反电动势必须泄放 |
| 振荡整形 | 三极管切换 LR 回路 | 储能释能形成波形 |

*RL 电路存在的意义，多半藏在**断电那一瞬间**——通电时电感规规矩矩像个短路，断电时它却把之前存的磁场能一次性还回来，冲出一个能打穿三极管的高压尖峰。理解 RL，就是理解这份"存款到期要取现"的脾气。*
