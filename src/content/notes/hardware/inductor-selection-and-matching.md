电感的物理本质在 [[inductor-basics]] 里讲过——本篇是**工程视角**：参数怎么算、型号怎么挑、以及它最容易被忽略的一项专长——**阻抗匹配**。

## 一、概述与基本公式

**概述**：电感是储能型被动电子元件，利用通电线圈产生磁场储存磁场能，阻碍电路中电流发生变化。

**基本特性**：通直流、阻交流；通低频、阻高频。

**功能**：通直流、阻交流、储存释放磁场能量、滤波、限流、续流保护、谐振选频。

**电感量 $L$**：衡量电感存储磁场能量能力的参数。它的大小与线圈的**匝数、磁芯的磁导率、线圈的几何形状**等因素有关。

### 线圈电感基本公式

$$L = \frac{\mu\mu_0 N^2 S}{l}$$

| 符号 | 含义 | 单位 |
|---|---|---|
| $L$ | 电感量 | 亨利（H） |
| $\mu$ | 磁芯的相对磁导率 | — |
| $\mu_0$ | 真空的磁导率，约 $4\pi \times 10^{-7}$ H/m | H/m |
| $N$ | 线圈的匝数 | — |
| $S$ | 线圈的横截面积 | 平方米（m²） |
| $l$ | 线圈的平均长度 | 米（m） |

> 💡 匝数 $N$ 是**平方**关系——匝数翻倍，电感量变四倍。这是电感设计里最"划算"的一个旋钮，也是最容易饱和翻车的地方。

### 电感定义式

电流越大，产生的磁场越多：

$$L = \frac{\Psi}{I}$$

其中 $\Psi$ 为磁通量（磁链），$I$ 为电流。

### 储能本质

储存磁场能量：

$$W = \frac{1}{2}LI^2$$

## 二、选型一般从哪些方面考虑？

答：**电感量、额定电流、直流电阻（DCR）、饱和电流 Isat、工作频率、封装尺寸、耐压、温漂和材质。**

| 方面 | 要点 |
|---|---|
| 电感量 | 按电路谐振、滤波、储能需求确定标称值 |
| 额定电流 | 直流/峰值电流不超规格，防饱和发热 |
| 直流电阻 DCR | 越小损耗越低，压降越小 |
| 饱和电流 Isat | 电流过大磁芯饱和，**电感骤降失效** |
| 工作频率 | 匹配电路频段，避开自谐振频率 SRF |
| 封装尺寸、耐压、温漂、材质 | 适配 PCB 空间与工况 |

> ⚠️ 电感选型最容易踩的坑是**只看电感量、不看饱和电流**：一旦磁芯饱和，电感量会断崖式下跌，滤波和储能同时失效，而万用表量上去却"看起来没坏"。

## 三、核心参数有哪些？

答：**电感值 L、直流电阻 DCR、额定电流、自谐振频率 SRF、品质因数 Q、磁芯材料和封装尺寸。**

| 参数 | 说明 |
|---|---|
| 电感值 $L$ | 基本储能参数，单位 µH / mH / H |
| 直流电阻 DCR | 铜线内阻，越小损耗越小 |
| 额定电流 | 含饱和电流、温升电流，防饱和过热 |
| 自谐振频率 SRF | **超出后失去电感特性** |
| 品质因数 $Q$ | 反映损耗高低，高频电路关键 |
| 磁芯材质 | 决定适用频率、饱和能力 |
| 封装尺寸 | 适配 PCB 布局与安装空间 |

## 四、核心特性

答：**电流不能突变；通直流阻交流，频率越高感抗越大。**

$$X_L = 2\pi fL$$

> 💡 这条公式就是电感的全部脾气：$f$ 越大感抗越大（所以阻高频），$f = 0$ 时感抗为零（所以通直流）。

## 五、为什么直流稳态条件下电感相当于短路？

答：因为直流稳态条件下**电流变化率、电感两端电压和感抗均为 0**。

1. 直流稳态电流恒定，电流变化率为 $di/dt = 0$。
2. 电感两端电压为 0，等同于导线短路：

$$U = L \cdot \frac{di}{dt}$$

3. 直流频率为 0，感抗为 0，无阻碍作用：

$$X_L = 2\pi fL \quad (f = 0)$$

> ⚠️ "直流短路"是**稳态**结论，不是瞬态结论。上电瞬间 $di/dt$ 很大，电感两端会出现明显的反电动势——这正是 [[rl-circuit-applications]] 里"消尖峰"要处理的电压浪涌来源。

## 六、电感用于阻抗匹配的作用、原理和接法

答：**作用**——抵消容性电抗，实现阻抗匹配，减少信号反射、降低传输损耗，最大化功率传输。

**原理**——感性电抗与容性电抗性质相反，串联/搭配电容可中和电抗分量，让负载阻抗与源阻抗模值、相位一致。

$$X_L = 2\pi fL$$

## 小结

| 要点 | 结论 |
|---|---|
| 电感量 | $L = \dfrac{\mu\mu_0 N^2 S}{l}$，匝数是平方关系 |
| 储能 | $W = \dfrac{1}{2}LI^2$ |
| 感抗 | $X_L = 2\pi fL$——阻高频、通直流 |
| 选型关键 | 电感量、DCR、额定电流、**Isat**、频率（避开 SRF） |
| 直流稳态 | $di/dt = 0$ → 两端电压为 0 → 等效短路 |
| 匹配接法 | 串联/并联电感 → L 型 → Π 型 → T 型 LC 网络 |

*电感与电容是一对镜像：**电容守电压、电感守电流；电容通高频、电感通低频**。阻抗匹配正是把这对镜像摆到正确的位置上——用电感的感性电抗去中和线路里的容性电抗，让前后级"看对眼"。*
