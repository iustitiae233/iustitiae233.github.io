电容的原理在 [[capacitor-basics]] 里讲过——本篇是**工程视角**：选型看什么、参数怎么读、放到电路里扮演什么角色。

## 一、概述与基本公式

**概述**：电容是储存电荷与电能的被动电子元件，广泛用于滤波、耦合、储能、定时等电路。

**基本特性**：通交流、隔直流；阻低频、通高频。

**功能**：储能、滤波、耦合、去耦、旁路、定时、振荡。

电容定义式——极板上的电荷量与两端电压的比值：

$$C = \frac{Q}{U}$$

| 符号 | 含义 | 单位 |
|---|---|---|
| $C$ | 电容量 | 法拉（F） |
| $U$ | 极板之间的电压 | 伏特（V） |
| $Q$ | 极板上的电荷量 | 库仑（C） |

**储能本质**：极板间电场储存电能。

$$W = \frac{1}{2}CU^2$$

## 二、选型一般从哪些方面考虑？

答：**介质材质、容值与精度、额定耐压、温度特性、封装尺寸、ESR 等效串联电阻、纹波电流、频率特性和应用场景。**

### ① 介质材质（最优先）

| 类型 | 特点与适用 |
|---|---|
| 陶瓷 MLCC | 高频滤波、去耦、小体积 |
| 电解电容 | 大容量、低频电源滤波、电源储能 |
| 钽电容 | 低 ESR、稳定、精密电路、**有极性** |
| 薄膜电容 | 高压、安规（X/Y 电容）、交流、谐振 |
| 云母电容 | 高频射频、高精度 |

### ② 容值与精度

- 滤波选低精度，振荡/采样选高精度
- 常规系列：E6 / E12 / E24
- 精度代号：F（±1%）、G（±2%）、J（±5%）、K（±10%）、M（±20%）

### ③ 额定耐压

- 交流电路看**峰值电压**，直流看**纹波峰值**
- 实际电压 ≤ 0.7~0.8 倍额定耐压

### ④ 温度范围与温度特性

- 普通：X7R（-55~125 ℃）
- Y5V / Z5U：温漂大，**不用于精密**电路
- 汽车/工业：必须宽温级

### ⑤ 封装尺寸

越小高频越好，功率越大选大封装。常见：0201 / 0402 / 0603 / 0805 / 1206。

### ⑥ ESR 等效串联电阻

- 电源滤波：优先**低 ESR**
- 高频去耦：必须**小 ESR**
- 电解：ESR 大，高频差

### ⑦ 纹波电流与温升

开关电源输出电容重点看——纹波超值会**发烫鼓包**。

### ⑧ 频率特性（自谐振频率 SRF）

工作频率**低于 SRF 才呈容性**；高频旁路必须选 SRF 高的小容值电容。

### ⑨ 漏电流

稳压、采样、基准电路**严控漏电流**。电解漏电流大，MLCC 极小。

### ⑩ 应用场景

| 场景 | 选型 |
|---|---|
| 电源去耦 | 100nF + 10µF 组合 |
| 谐振/晶振起振 | NP0 / X7R，低温漂 |
| 安规 Y 电容 | 安规认证、耐压等级 |
| 阻容降压 | CBB 薄膜电容 |
| 射频匹配 | 高 Q 值高频电容 |
| 储能 | 低压大容量电解电容 |

## 三、核心参数有哪些？

答：**耐压、容量精度、ESR、漏电流、温漂、温度范围、纹波电流、频率特性、极性、寿命。**

1. **额定耐压**：长期工作最大允许电压，选型必须留余量，严禁超压。
2. **标称容量 & 精度**：实际容值偏差，常用 ±5%、±10%、±20%，精密电路选高精度。
3. **ESR 等效串联电阻**：数值越小，高频滤波、纹波抑制能力越强，电源电路重点看。
4. **漏电流**：电容静置漏电大小，模拟采样、基准电路必须选**低漏电**。
5. **温度系数**：温度变化引起容量波动，C0G 最小，Y5V 最差，高低温场景优先 X7R / C0G。
6. **使用温度范围**：区分民用、工业级、车载级，决定工作环境适配性。
7. **纹波电流**：允许通过的最大交流纹波电流，超量发热鼓包损坏。
8. **频率特性**：不同频率下容值、阻抗变化，决定适用低频 / 高频场景。
9. **极性**：分有极性（电解、钽）、无极性（陶瓷、薄膜），**极性不可接反**。
10. **寿命**：高温、大电流环境会大幅缩短电容使用寿命。
11. **绝缘电阻**：绝缘性能，安规、高压电路重点参数。

## 四、电容两端的电压为什么不能突变？

答：电容储能靠电荷积累，瞬间变压需无穷大电流，故电压无法突变。

核心公式：

$$i = C \cdot \frac{du}{dt}$$

| 符号 | 含义 |
|---|---|
| $i$ | 电容电流 |
| $C$ | 电容值 |
| $du/dt$ | 电压变化快慢 |

电压突变时 $\dfrac{du}{dt} \approx \infty \Rightarrow i = C \cdot \infty = \infty$——因为现实电路不可能出现无穷大电流，所以电压没法瞬间跳变。

**物理本质**：电容靠储存电荷升压 $Q = CU$。电压升高必须慢慢充进电荷，电荷不能一瞬间堆满，电压自然不能突变。

**分析电路瞬态时**（换路瞬间 $t = 0^+$），直接用换路前的电压当作瞬间电压：

$$U_C(0^+) = U_C(0^-)$$

## 五、电容有什么作用？

答：**储能、隔直通交、滤波、耦合、去耦、旁路、谐振/振荡、移相、阻容降压、延时定和阻抗匹配。**

| 作用 | 说明 |
|---|---|
| 储能 | 瞬间供电、断电续流、缓冲能量 |
| 隔直通交 | 隔断直流，传递交流信号 |
| 滤波 | 滤除电源杂波、纹波，平滑电压 |
| 耦合 | 级间传递信号，隔离直流电位 |
| 去耦 | IC 就近供电，稳定芯片电压，抗干扰 |
| 旁路 | 高频杂波直接接地泄放 |
| 谐振/振荡 | 搭配电感做 LC 振荡、晶振起振 |
| 移相 | 改变电压电流相位，电机启动、调光 |
| 阻容降压 | 阻容降压电路降电压 |
| 延时定时 | RC 充放电做延时、复位、时序 |
| 阻抗匹配 | 射频、信号线路调阻抗 |

## 六、耦合、去耦和旁路电容的区别是什么？

答：**耦合电容传信号、隔直流；去耦电容稳电源、补电流；旁路电容引杂波下地。**

![[cap-roles-amp-circuit.png|共射极放大电路中耦合电容 C1、去耦电容 C2 和旁路电容 C3 的标注位置电路图]]

*图：同一张共射极放大电路上标出三种角色的位置——C1 在信号通路中间，C2 在 VCC 到地，C3 并在发射极电阻上*

### ① 耦合电容（C1 耦合）

| 项 | 内容 |
|---|---|
| 作用 | 传递交流信号，隔断直流电位 |
| 位置 | 两级电路中间 |
| 特点 | 不让前后级直流互相影响；只过音频/视频/交流信号 |
| 常用值 | 1µF、10µF |

### ② 去耦电容（C2 去耦）

| 项 | 内容 |
|---|---|
| 作用 | 给 IC 就近储能，稳定电源电压 |
| 位置 | 芯片 VCC 引脚就近对地 |
| 特点 | 瞬间大电流供电；抑制电源波动、防止串扰 |
| 标配搭配 | 0.1µF + 10µF（小容值滤高频，大容值滤低频） |

### ③ 旁路电容（C3 旁路）

| 项 | 内容 |
|---|---|
| 作用 | 把高频干扰直接短路到地 |
| 位置 | 信号脚对地 |
| 特点 | 滤除杂波，净化主信号 |
| 常用值 | 0.1µF、100nF |

> 💡 一句话区分：**耦合是"让信号过去、把直流留下"；去耦是"给芯片就近备电"；旁路是"把杂波引到地"**。三者位置不同，但用的都是电容"隔直通交"这一条本性。

## 七、共射极放大电路旁路电容 Ce 有什么作用？

答：隔直通交，稳定直流工作点，消除发射极电阻对交流信号的负反馈，提高电压放大倍数。

![[cap-ce-bypass.png|共射极放大电路中发射极旁路电容 Ce 与耦合电容 Cb、去耦电容 C2 的电路图]]

*图：Ce 并联在发射极电阻 Re 两端，Cb 做输入耦合，C2 做电源去耦*

### ① 电路位置

并联在发射极电阻 Re 两端。

### ② 核心作用

**1. 通交流、隔直流**

- 直流电流：走 Re，产生直流负反馈，稳定静态工作点。
- 交流信号：直接走 Ce，短路 Re。

**2. 提升电压放大倍数**

- 若没有 Ce，交流信号也经过 Re，会产生强烈交流负反馈，放大倍数大幅下降；
- 并联 Ce 后交流不受 Re 阻碍，放大能力恢复正常。

> ⚠️ 如果只在发射极并电容却忘了它同时短路了交流负反馈，很容易误以为增益没变——Ce 的意义正在于"只让交流绕开 Re"。

## 八、为什么电源旁边放 0.1µF + 10µF 电容？

答：**大电容 10µF 滤低频大波纹，小电容 0.1µF 滤高频杂波，远近搭配稳压降噪。**

![[cap-power-01u-10u.png|芯片电源脚旁并联 0.1µF 与 10µF 两个电容再接到 VCC 的电路图]]

*图：0.1µF 与 10µF 并联接在 VCC 与地之间，再送到芯片电源脚*

| 电容 | 作用 | 频段 |
|---|---|---|
| 0.1µF（小） | 滤高频干扰，**响应快** | 专滤 10MHz~100MHz 高频干扰、尖峰脉冲、开关噪声 |
| 10µF（大） | 滤低频纹波，**储能稳压** | 滤几十 Hz~几百 kHz 低频电源纹波、电压波动 |
| 1µF（扩展） | 中频段补充 | 滤几百 kHz~几 MHz 中频干扰、电路耦合噪声 |

### 去耦电容为什么要靠近芯片电源脚？

答：**缩短走线，减小引线电感，保证高频噪声瞬间快速泄放，稳压滤波效果最强。**

> 💡 电容再好，走线一长就多出一段引线电感——高频下这段电感会挡住电容的"就近备电"能力，所以"贴近电源脚"不是建议而是硬要求（一般 < 3mm）。

## 九、电容串联/并联特点

答：**并联容量相加、耐压不变；串联容量变小、耐压升高。**

$$C_{并总} = C_1 + C_2 + \cdots \qquad \frac{1}{C_{串总}} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots$$

> ⚠️ 串联虽然能提高耐压，但各电容的漏电流/ESR 不一致会导致**分压不均**，实际工程里高压场合更倾向于直接选高耐压单颗（并在每颗上并接均压电阻）。

## 小结

- **选型十看**：介质 → 容值精度 → 耐压 → 温度 → 封装 → ESR → 纹波 → 频率 → 漏电 → 场景。
- **核心参数**的核心是两类矛盾：**耐压/容值**决定能不能用，**ESR/漏电/温漂**决定用得好不好。
- **电压不能突变** $U_C(0^+)=U_C(0^-)$，是分析一切 RC 瞬态的地基（见 [[rc-circuit-applications]]）。
- **三种角色**：耦合管信号通路，去耦管芯片供电，旁路管杂波下地。
- 电源脚旁 **0.1µF 贴近 + 10µF 兜底**，且必须贴近芯片引脚才有意义。

*电容的选型手册看起来很厚，但真正决定成败的只有两条：**耐压与容值决定能不能用，ESR 与温漂决定用得好不好**；而它在电路里的身份，永远取决于"放在哪个位置"——串在信号路上是耦合，贴在电源脚上是去耦，并在信号脚上是旁路。*
