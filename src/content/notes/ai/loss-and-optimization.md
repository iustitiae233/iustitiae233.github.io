训练神经网络说到底只有两件事：**用一个标量说清楚"现在错得有多离谱"（损失函数），然后照着这个标量的坡度改参数（优化器）**。前者决定模型在乎什么，后者决定它能多快到达。梯度的计算方式见 [[backpropagation]]，防止"背答案"的手段见 [[training-stability-and-regularization]]。入口在 [[ai/overview]]。

## 一、损失函数——量化"错得有多离谱"

训练的核心任务是找一组最优的权重和偏置（GPT-3 里这意味着约 1750 亿个参数），让预测尽可能接近真实答案。为此需要一个客观的打分标准。

不同任务需要不同的衡量方式：

| 任务类型 | 常用损失函数 | 数学表达式 | 通俗解释 |
|---|---|---|---|
| 回归（预测数值） | 均方误差（MSE） | $\frac{1}{n}\sum_i (y_i - \hat{y}_i)^2$ | 预测房价比实际高 5 万还是低 5 万，惩罚一样；但离群点会被平方放大 |
| 回归（对异常值不敏感） | 平均绝对误差（MAE） | $\frac{1}{n}\sum_i \lvert y_i - \hat{y}_i \rvert$ | 只看差了多少、不看方向，个别离谱的样本不至于带偏整个模型 |
| 二分类 | 二元交叉熵（BCE） | $-\left[y\log\hat{y} + (1-y)\log(1-\hat{y})\right]$ | 当你说"99% 确定是猫"但其实是狗时，惩罚极大 |
| 多分类 | 分类交叉熵 | $-\sum_i y_i \log \hat{y}_i$ | 1000 个类别中，正确答案那一类的概率应该最高 |
| LLM 预训练 | 交叉熵损失 | $-\log P(\text{正确的下一个 token})$ | 在十万个候选词中，模型给正确那个词的概率有多高 |

> 💡 损失函数的选择直接决定了模型"在乎什么"。用 MSE 训练的图像生成模型会倾向于输出"模糊但安全的平均值"——因为平方惩罚下，糊掉能稳妥地降低期望误差；换成感知损失（Perceptual Loss）就更容易得到锐利逼真的结果，即使像素值与真实图像并不逐点一致。

## 二、梯度下降——一步一步走向最优解

假设你蒙着眼站在山顶，想走到山谷最低点。你能做的只有感受脚下的坡度，然后朝最陡的下坡方向迈一小步，不断重复。

$$\theta_{\text{new}} = \theta_{\text{old}} - \eta \cdot \nabla J(\theta)$$

| 符号 | 含义 |
|---|---|
| $\theta$（参数） | 所有要优化的权重和偏置的总称 |
| $J(\theta)$（损失函数） | 当前参数下的"错误程度" |
| $\nabla J(\theta)$（梯度） | 损失对每个参数的偏导——告诉往哪个方向调能让损失下降最快。某个参数上梯度为正，说明增大它会让损失增加，所以要**减去**它 |
| $\eta$（学习率） | 每一步迈多大。太小则收敛极慢（像蚂蚁下山），太大则可能跳过最优点甚至发散（像从山上直接跳下去） |

**三种实现方式**：

| 方式 | 每次更新用的数据量 | 优点 | 缺点 |
|---|---|---|---|
| 批量梯度下降（BGD） | 整个训练集 | 梯度精确、收敛稳定 | 百万级数据时一次更新都算不动 |
| 随机梯度下降（SGD） | 1 个样本 | 极快，可以"边看边学" | 梯度噪声大，收敛路径像醉汉走路 |
| **小批量梯度下降（Mini-batch SGD）** | 32~256 个样本 | 兼顾速度与稳定性，能喂饱 GPU 并行 | batch size 需要调参 |

现代深度学习用的几乎都是 Mini-batch SGD 或其变体，典型 batch size 是 32 或 64——既让 GPU 吃饱，又保证梯度方向大致正确。

## 三、优化器的演进——每一步都在解决前一步的痛点

普通 SGD 有一个致命缺陷：**学习率对所有参数一视同仁**。在一个狭长的山谷里，有些方向陡（需要小步）、有些方向平（需要大步），你却只能用同一个步伐，结果就是 zigzag 式的低效前进。

| 优化器 | 年份 | 核心思想 | 解决的问题 | 遗留问题 / 适用场景 |
|---|---|---|---|---|
| SGD | 1951 | 纯梯度下降 | 最基础 | 需要精细调参 |
| SGD + Momentum | 1964 | 积累过去梯度的指数移动平均（惯性） | 减少 zigzag 振荡、加速穿过平坦区 | 比纯 SGD 收敛更快 |
| NAG | 1983 | 先在惯性方向上"瞄一眼"再算梯度 | 让动量更有"远见" | Momentum 的改进版 |
| AdaGrad | 2011 | 按历史梯度平方和自适应调学习率 | 稀疏特征得到更大更新（适合 NLP） | 累加导致学习率过早衰减到 0 |
| RMSprop | 2012 | 用指数移动平均替代 AdaGrad 的累加 | 修掉 AdaGrad 学习率过早衰减 | RNN 训练中尤其有效 |
| **Adam** | 2014 | Momentum + RMSprop 的结合体 | 两者优势兼得，调参简单 | 2014–2020 的绝对王者 |
| **AdamW** | 2017 | **把权重衰减从自适应学习率中解耦**，变成独立项 | L2 惩罚在自适应学习率下**不等价**于权重衰减，AdamW 恢复了后者的语义 | Transformer 训练的事实标准 |
| LAMB | 2019 | 层级自适应学习率 | 支持极大 batch size（32K+） | 分布式训练大模型 |

> ⚠️ 常说"Adam 的 L2 实现有 bug"，更准确的说法是**不等价**：在自适应学习率下，把 L2 惩罚加进梯度里，会让每个参数上实际施加的衰减量被它自己的梯度尺度缩放——梯度大的参数反而被衰减得少。AdamW 干脆把权重衰减挪出梯度更新，作为一个独立项直接作用在参数上，正则的强度才重新可控。2021 年后几乎所有 LLM 训练都用 AdamW，不是偶然。

## 小结

| 要点 | 结论 |
|---|---|
| 损失函数 | 定义什么叫"好的预测"：交叉熵统治分类，MSE / MAE 统治回归 |
| MSE vs MAE | MSE 放大离群点，MAE 更稳健但零点不可导 |
| 梯度下降 | $\theta \leftarrow \theta - \eta \nabla J(\theta)$，学习率是最重要的超参数之一 |
| 三种实现 | 实际只用 Mini-batch——单样本噪声太大，全量算不动 |
| 优化器主线 | 从"统一学习率"走向"每参数自适应"，再走向"把正则解耦" |
| AdamW | 权重衰减必须独立于自适应学习率施加，否则正则强度失控 |

*优化的历史就是一部"如何让每个参数走自己的步子"的历史——而最后发现，最需要被独立对待的竟是正则项本身。*
