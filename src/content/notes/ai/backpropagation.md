如果说梯度下降回答"往哪走"，反向传播回答的是"**每一步该往哪走**"——它把微积分里的链式法则变成了一台可工业化的求导机器。更新规则本身见 [[loss-and-optimization]]，让梯度在深层网络里不消失的手段见 [[training-stability-and-regularization]]。入口在 [[ai/overview]]。

## 一、四步流程

反向传播（Backpropagation）1986 年由 Rumelhart、Hinton 和 Williams 正式提出并推广，核心流程只有四步：

| 步骤 | 做什么 |
|---|---|
| 1. 前向传播（Forward Pass） | 输入从第一层流到最后一层，逐层计算得到预测值；**同时缓存每一层的中间结果**——反向时要用 |
| 2. 计算损失（Compute Loss） | 把预测值和真实标签比较，算出一个代表"差距"的标量 |
| 3. 反向传播（Backward Pass） | 从输出层开始，用**链式法则**逐层反算"损失对每个参数的偏导数"，也就是每个参数对最终误差的贡献度 |
| 4. 参数更新（Parameter Update） | 交给优化器（如 AdamW）按梯度更新所有权重和偏置 |

第 1 步那句"同时缓存中间结果"是整件事的关键：链式法则要求把局部导数一层层乘起来，而这些局部导数依赖前向时算出的值。**用显存换计算**是反向传播的工程本质。

## 二、一个可以手算的例子

假设一个极简网络：输入 $x = 2$，权重 $w = 3$，偏置 $b = 1$，激活函数 $f(z) = z^2$（仅为演示），真实标签 $y = 50$，学习率 $\eta = 0.01$。

**前向传播**

$$z = wx + b = 3 \times 2 + 1 = 7, \qquad \hat{y} = f(z) = 7^2 = 49$$

**计算损失**

$$L = (\hat{y} - y)^2 = (49 - 50)^2 = 1$$

**反向传播**（链式法则自外向内逐层展开）

$$\frac{\partial L}{\partial \hat{y}} = 2(\hat{y} - y) = -2$$

$$\frac{\partial L}{\partial z} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} = (-2) \times (2 \times 7) = -28$$

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial w} = (-28) \times 2 = -56, \qquad \frac{\partial L}{\partial b} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial b} = (-28) \times 1 = -28$$

**参数更新**

$$w_{\text{new}} = 3 - 0.01 \times (-56) = 3.56, \qquad b_{\text{new}} = 1 - 0.01 \times (-28) = 1.28$$

注意 $w$ 和 $b$ 都**增大**了——因为梯度是负的，减去负数等于加上正数。这一步让输出从 49 更靠近了 50。

> 💡 上面这个网络只有两个参数，所以链式法则显得小题大做。真正的意义在于：**无论多少层、多少参数，反向传播的代价都只有一次前向传播的两倍左右**——每个参数都免费得到自己的梯度。今天千亿参数的模型能被训练，靠的就是这个性质。

## 三、它和梯度下降的分工

初学者常把两者混为一谈，其实边界很清楚：

| | 反向传播 | 梯度下降 / 优化器 |
|---|---|---|
| 回答的问题 | 每个参数的梯度**是多少** | 拿到梯度后**怎么走** |
| 数学工具 | 链式法则（偏导） | 更新规则（含学习率、动量、自适应缩放） |
| 是否关心历史 | 不关心，每次独立求导 | 关心，Momentum / Adam 都依赖历史梯度 |
| 类比 | 复盘时追溯"这道题为什么扣分" | 决定下次复习要投入多少精力 |

## 小结

| 要点 | 结论 |
|---|---|
| 四步流程 | 前向 → 算损失 → 反向求导 → 更新参数 |
| 为什么缓存 | 局部导数依赖前向的中间值，用显存换计算 |
| 复杂度 | 一次反向 ≈ 两次前向，与参数量无关地摊薄到每个参数 |
| 与梯度下降分工 | 反向传播算梯度，优化器决定怎么用梯度 |
| 提出时间 | 1986 年由 Rumelhart、Hinton、Williams 推广，至今仍是训练引擎 |

*反向传播本质上是一次高效的"集体问责"——从最终误差出发，把责任按链式法则逐层摊回到每一个参数身上，而且摊一次的成本只比前向贵一倍。*
