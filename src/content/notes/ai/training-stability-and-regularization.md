深层网络训练有两条独立的战线：一条是**让梯度活着传回浅层**（稳定性），另一条是**别让它把训练集背下来**（正则化）。前者靠归一化与残差连接，后者靠各种加噪声与加惩罚的手段。梯度的来源见 [[backpropagation]]，优化器的选择见 [[loss-and-optimization]]。入口在 [[ai/overview]]。

## 一、梯度消失与梯度爆炸

**梯度消失**：梯度从输出层往浅层传时，每过一层就乘上一串局部导数。如果这些导数普遍小于 1（Sigmoid 的导数最大只有 0.25），几十层乘下来梯度就衰减到浮点数的噪声级别，浅层几乎学不到任何东西。

**梯度爆炸**：反过来，如果权重偏大，连乘的结果指数级增长，参数一步更新就飞到离谱的数值，整个网络输出 NaN。

两者是同一个现象的两面——**深度带来的连乘**。

| 技术 | 提出年份 | 核心原理 |
|---|---|---|
| ReLU 激活函数 | 2010 | 正区间梯度恒为 1，连乘不再衰减 |
| Xavier / Glorot 初始化 | 2010 | 让每层输出的方差与输入相当，前向不炸不退 |
| He / Kaiming 初始化 | 2015 | Xavier 的 ReLU 适配版，补偿 ReLU 砍掉一半信号 |
| Batch Normalization | 2015 | 对每层输出按 batch 统计量标准化（均值 0、方差 1），再做可学习的缩放与偏移 |
| Layer Normalization | 2016 | 对每个样本独立标准化，不受 batch size 影响，适合 NLP 与 Transformer |
| 残差连接（Skip Connection） | 2015 | 见下一节 |
| 梯度裁剪（Gradient Clipping） | — | 梯度范数超过阈值就等比缩回，专治爆炸 |

## 二、BatchNorm 与 LayerNorm 的分工

两者形式相似，差别在**沿哪个维度统计**：

| | BatchNorm | LayerNorm |
|---|---|---|
| 统计范围 | 同一个通道、跨整个 batch 的样本 | 同一个样本、跨该样本的所有特征 |
| 依赖 batch size | 强依赖——batch 太小统计量不稳 | 不依赖，batch=1 也成立 |
| 推理时 | 需要滑动平均保存的全局统计量 | 直接用当前样本，训练推理一致 |
| 主战场 | CNN 视觉模型 | Transformer / NLP |

这就是为什么序列长度和 batch 都高度可变的 LLM 一律用 LayerNorm（或其变体 RMSNorm）——它不需要"别人"的统计量就能归一化。

## 三、残差连接——让上千层网络可训练

**残差连接（Residual Connection / Skip Connection）** 的数学形式只有一行：

$$\text{输出} = F(\text{输入}) + \text{输入}$$

![[ai-residual-block.png|残差块结构对比：左侧为普通堆叠的 Layer i 到 Layer i+n 输出 F(x)，右侧为带 identity 旁路支线的残差块，主干输出 F(x) 与恒等支路的 x 相加得到 F(x)+x]]

*图：左为普通堆叠——若干层输出 $F(x)$；右为残差块——输入 $x$ 另走一条 identity 旁路，与主干输出逐元素相加得到 $F(x) + x$*

为什么这个加法如此重要？因为它给梯度提供了一条"高速公路"：反向传播时，那个恒等项的导数是 1，于是

$$\frac{\partial(F(x) + x)}{\partial x} = F'(x) + 1$$

**那个 $+1$ 保证了即使 $F'(x)$ 接近 0，梯度也不会归零。** 这不是"缓解"，而是从结构上消除了一整类失效模式。

**ResNet** 凭这个设计拿下了 2015 年 ImageNet 图像识别冠军：152 层 vs 此前 VGG 的 19 层，top-5 错误率降到 3.57%（集成模型成绩），低于常被引用的人类约 5% 的水平。更能说明问题的是 ResNet 论文里那组对照实验——**56 层的普通网络反而比 20 层的训练误差更高，且不是过拟合：训练误差本身就更大。** 这就是"退化问题（degradation）"，残差连接正是为它设计的。

此后残差连接成了所有深层架构的标配：Transformer 的每个子层、扩散模型的 U-Net、ViT，无处不见（[[transformer-architecture]]、[[vit]]）。

## 四、正则化——防止"死记硬背"

当参数量远超训练样本数时，网络完全可能"背下"所有训练样本而丧失泛化能力，这就是**过拟合（Overfitting）**。

| 方法 | 原理 | 注意事项 |
|---|---|---|
| L2 权重衰减 | 在损失中加入权重平方和的惩罚项，鼓励更小的权重 | 现代实现通常直接用 AdamW 的 `weight_decay`——解耦后正则强度才可控，见 [[loss-and-optimization]] |
| Dropout | 训练时随机把一部分神经元置零，迫使网络不依赖任何单一神经元 | 推理时必须关闭；比例通常 0.2~0.5 |
| DropPath | 随机丢弃整条残差路径，适合极深网络 | ViT 与 Swin Transformer 常用 |
| 数据增强 | 对训练数据做随机变换（翻转、裁剪、加噪），变相扩增数据量 | 几乎零成本，视觉任务必用 |
| Early Stopping | 验证集损失不再下降时停止训练 | 最简单也最有效的手段之一 |
| **Label Smoothing** | 不要求模型对正确类别输出概率 1，而是给错误类别分配一点微小概率（如 $\varepsilon = 0.1$） | 抑制"过度自信"，改善校准；原版 Transformer（Vaswani et al. 2017）就用了 $\varepsilon = 0.1$ |

> ⚠️ 常见说法"LLM 训练里不需要 Label Smoothing"是过强的断言。准确的说法是：**它不再是大多数 LLM 预训练的标配**（大规模数据本身就有正则效果，且现代配方更关心校准与损失曲线），但它并没有失效——不让模型把概率全压在一个 token 上，在数据量有限或需要概率校准时依然有用。

## 小结

| 要点 | 结论 |
|---|---|
| 梯度消失/爆炸 | 同源——深度带来的连乘；导数普遍 <1 则消失，普遍 >1 则爆炸 |
| 解决方案脉络 | ReLU → 合适的初始化 → 归一化 → 残差连接，逐层加固 |
| BatchNorm vs LayerNorm | 差别在统计维度：跨 batch 还是跨特征；Transformer 用后者 |
| 残差连接 | $F(x) + x$，导数里的 $+1$ 从结构上消除梯度归零 |
| 退化问题 | 更深不等于更好，甚至训练误差更差——这不是过拟合 |
| 正则化 | L2 / Dropout / 数据增强 / Early Stopping / Label Smoothing 各管一段 |

*稳定性解决的是"信号还能不能传下去"，正则化解决的是"传下去的信号是不是在背答案"——前者是深度的入场券，后者是泛化的护城河。*
