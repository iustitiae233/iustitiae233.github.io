深度学习最反直觉的一条经验规律是：**模型变大变好这件事，是可以被预测的**。缩放定律把"大"从一个形容词变成了一条曲线，也把"该多大"变成了一个可以算的优化问题。层内构造见 [[transformer-architecture]]，训练流程见 [[llm-training-pipeline]]。本分类全部笔记见 [AI 原理](/notes/ai/)。

## 一、缩放定律：性能是幂律

**缩放定律（Scaling Laws）** 指出：模型性能（通常看损失）与参数量、数据量、计算量之间呈**平滑的幂律关系**。用双对数坐标画出来是一条直线——意味着在相当宽的范围内，投入增加带来的收益是可外推、可预期的。

这是大模型时代最重要的方法论变化之一：不必每次都训一个完整模型来试，用小模型的曲线就能推出大模型大致会在哪。

## 二、Chinchilla：纠正"只要参数大"

早期的大模型竞赛集中在**参数量**上——Gopher 280B、GPT-3 175B，而训练数据只有 300B token 左右。2022 年 DeepMind 的 Chinchilla 论文（Hoffmann et al., *Training Compute-Optimal Large Language Models*）指出：**这些模型普遍严重训练不足。**

> 💡 核心结论：在**给定算力预算**的前提下，参数量与训练 token 数应当大致**同步放大**——论文估计的近似比例约为**每个参数配 20 个 token**。作为证据，同算力下训练的 Chinchilla（70B 参数、1.4T token）在大量任务上超过了参数量四倍的 Gopher（280B 参数、300B token）。

这条结论的准确表述是**算力在参数量与数据量之间的分配问题**：不是"数据越多越好"，而是"参数翻倍时，数据也得跟着翻倍才划算"。它直接推翻了"堆参数、数据随便给点"的路线，此后主流模型的 token/参数比普遍向 20 靠拢甚至更高。

## 三、别把"算力配比"与"数据质量"混为一谈

这是两个**相互独立**的杠杆，常被混着讲：

| 杠杆 | 在优化什么 | 代表工作 |
|---|---|---|
| **算力配比**（Chinchilla） | 固定算力下，参数量与 token 数怎么分 | Hoffmann et al. 2022：约 20 token/参数 |
| **数据质量** | 单位 token 能带来多少有效学习信号 | 精细清洗与去重（FineWeb 等）、教科书级语料（phi 系列）、以高质量配比见长的开源配方 |

Chinchilla 与"数据质量 vs 数据数量"**无关**。质量这条线回答的是另一个问题：**同样多的 token，信息密度能不能更高？** 如果能，那么达到同等效果需要的 token 就更少——这才是"数据工程"作为一项专业工作真正的立足点，而不是 Chinchilla 的直接推论。

## 四、涌现能力：现象与争议

**涌现能力（Emergent Abilities）** 指的是：代码生成、多步逻辑推理、多语言翻译这类能力，在模型规模跨过某个临界点后**突然出现**，而小模型上完全不存在。这些能力不是被显式编程的，被认为是海量数据与充分参数空间下自发形成的行为。

需要说明的是，这个现象本身存在方法学争议：有研究指出，部分"突然出现"是**评价指标的产物**——如果指标是"整题全对"这种非连续的打分（0 或 1），曲线自然会出现台阶；换成连续指标（如 token 级准确率）后，进步往往是平滑的。

无论哪种解释，工程上的结论是一样的：**有些能力确实只有超过某个规模才划算去做**，而"差不多能用"与"真的能用"之间可能隔着一段看起来很平的曲线。

## 五、层深带来的能力分层

除了参数总量，**层数**本身也带来一种分工。以 GPT-3 的 96 层为例：

| 层段 | 主要在做的事 |
|---|---|
| 浅层（1–10 层） | 基础语法结构与局部词间关系 |
| 中层（11–50 层） | 更复杂的语义依赖、指代关系、基本事实知识 |
| 深层（51–96+ 层） | 抽象推理、多跳逻辑链、隐含意图、世界知识的综合运用 |

配上前馈网络存储知识的角色（[[transformer-architecture]]），可以把一个深层模型粗略理解为：**浅层在解析、中层在检索、深层在推理**——每一层逐步提炼更高级的语言理解。

## 小结

| 要点 | 结论 |
|---|---|
| 缩放定律 | 损失与参数量/数据量/算力呈平滑幂律，可外推 |
| Chinchilla 的结论 | 固定算力下参数与 token 应同步放大，约 20 token/参数 |
| 它纠正了什么 | "只要参数大就行"——Gopher 280B 被 Chinchilla 70B 超越 |
| 与数据质量的关系 | 两条独立杠杆；质量线关心单位 token 的信息密度 |
| 涌现能力 | 现象存在，但"突然"有多少是度量造成的仍有争议 |
| 层深分工 | 浅层语法 → 中层知识 → 深层推理 |

*缩放定律把"把模型做大"从信念变成了工程；Chinchilla 则提醒，做大只是分子，分母上还站着一个同样重要的数据量。*
