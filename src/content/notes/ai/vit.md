CNN 把"局部性"写死在结构里，ViT 把这条假设整个删掉——**把图像切成块，当成一句话交给 Transformer**。它证明的不是"注意力更好"，而是"当数据足够多时，先验反而是负担"。注意力机制本身见 [[self-attention]]，CNN 的先验从哪里来见 [[cnn-basics]]。本分类全部笔记见 [AI 原理](/notes/ai/)。

## 一、为什么 CNN 不够了

CNN 有一个与生俱来的**归纳偏置（Inductive Bias）**：它假设图像的特征是**局部的、平移不变的**。这带来两个后果——卷积核一次只能看到一个小区域（感受野是局部的），要建立全局联系必须堆很多层。

这个偏置是双刃的：

| 数据条件 | 归纳偏置的作用 |
|---|---|
| 数据不足 | **优势**——把搜索空间约束在合理的结构里，等于免费注入了正确先验 |
| 数据海量 | **限制**——模型被"局部优先"的假设束缚，天花板被人为压低 |

2020 年 Google 提出 **Vision Transformer (ViT)**，直接挑战这个假设：**如果给 Transformer 足够多的训练数据，它不需要任何局部性先验，也能学出不逊于 CNN 的视觉理解。**

## 二、ViT 的核心流程

思路直截了当——把图像当成文本处理：

| 步骤 | 内容 |
|---|---|
| 1 | 把图像切成固定大小的 **Patch**（如 16×16 像素块）。224×224 图像 → 14×14 = 196 个 Patch |
| 2 | 每个 Patch 拉平成一个向量：$16 \times 16 \times 3 = 768$ 维 |
| 3 | 通过线性投影层映射到 Transformer 的嵌入维度 |
| 4 | 加上可学习的位置编码（Transformer 本身不知道 Patch 之间的空间关系） |
| 5 | 在最前面加一个可学习的 `[CLS]` token（沿用 BERT 的做法），它的最终输出用于分类 |
| 6 | 整个序列送入标准 Transformer 编码器 |

一张 224×224 的图像最终变成 **197 个 token**（196 个 Patch + 1 个 CLS），然后就像处理一段 197 个词的句子一样全部交给 Transformer。

注意第 3 步：**Patch 的线性投影层，作用上等价于一个"核大小 = 步长 = 16"的卷积层。** 所以 ViT 不是"没有卷积"，而是把卷积压缩成了唯一的一次、且不再堆叠——之后全交给注意力。

## 三、CNN 与 ViT 的逐项对比

| 特性 | CNN | Vision Transformer |
|---|---|---|
| 核心操作 | 局部卷积（3×3 或 5×5 滑动窗口） | 全局自注意力（每个 patch 看到所有 patch） |
| 归纳偏置 | 强——局部性 + 平移不变性 | 弱——几乎全靠数据学 |
| 数据需求 | 较少（十万量级即可训练） | 海量（百万量级才能发挥优势） |
| 全局感受野 | 需要堆很多层 | **第一层就能看到任意两个区域** |
| 计算复杂度 | 与卷积核大小和像素数近似线性 | $O(n^2)$——与 patch 数量的平方成正比 |
| 位置信息 | 天然编码在空间结构中 | 需要显式位置编码 |
| 多模态兼容性 | 专为图像设计 | **与文本 Transformer 同构，天然适合多模态** |

> 💡 这张表里最值得记住的是**数据需求那一行**：ViT 在小数据集上打不过 CNN，在超大数据集上反超。这解释了为什么 ViT 是 Google 提出来的——它需要 JFT-300M 这种量级的数据才能兑现潜力。**"哪个架构更好"这个问题从来不脱离数据规模单独成立。**

最后一行决定了后续十年的走向。多模态模型需要把图像和文本送进**同一个** Transformer——CNN 是异质的，ViT 与语言模型同构。所以现代多模态系统几乎全部采用 Transformer / ViT 作为视觉编码器，理由不是精度，而是**架构可拼接**（见 [[multimodal-models]]）。

## 四、ViT 的进化——层次化 Transformer

原始 ViT 有一个问题：所有层用相同的 patch 分辨率，缺少 CNN 那种"从细到粗"的多尺度层次——检测和分割任务特别依赖这个层次。

| 工作 | 改进 |
|---|---|
| **Swin Transformer**（2021） | 引入分层结构与移动窗口注意力（Shifted Window Attention），复杂度从 $O(n^2)$ 降到与像素数线性相关，同时恢复多尺度特征；获 ICCV 2021 最佳论文奖 |
| PVT（Pyramid Vision Transformer） | 类似 CNN 的逐层降采样结构，适合做检测与分割的骨干网络 |
| DINO / DINOv2（Meta） | 自监督训练的 ViT，不需要标注数据就能学到强视觉特征——其注意力图可以直接当作无监督的语义分割结果 |

## 小结

| 要点 | 结论 |
|---|---|
| 归纳偏置 | CNN 强（局部 + 平移不变），ViT 弱（几乎无先验） |
| 数据依赖 | 偏置在数据少时是优势，数据多时是天花板 |
| ViT 流程 | 切 Patch → 拉平 → 线性投影 → 加位置编码 → 加 CLS → Transformer |
| 与卷积的关系 | Patch 嵌入层本身就是一个大步长卷积，只是不再堆叠 |
| 复杂度 | 全局注意力 $O(n^2)$，Swin 的窗口注意力把它拉回线性 |
| 真正的胜负手 | 与语言模型同构，让多模态拼接成为可能 |

*ViT 的价值与其说是"更强的视觉模型"，不如说是**统一**——当图像和文本都是 token 序列，多模态就不再需要翻译层，只需要拼接序列。*
